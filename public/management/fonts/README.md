# 本地中文字体

Noto Sans SC，可变字重 100–900。字体文件来自公开 npm 包 `@fontsource-variable/noto-sans-sc@5.3.0`；字体采用 SIL Open Font License 1.1，完整许可见 `OFL.txt`。

在 HTML 的应用样式之前加载 `assets/fonts/fonts.css`，界面字体设为 `"Noto Sans SC", "Microsoft YaHei", sans-serif`。本目录只含 WOFF2 及对应 Unicode 分段，浏览器按实际文字按需加载；不需要 CDN 或联网。导出截图时等待 `document.fonts.ready`。

来源：https://www.npmjs.com/package/@fontsource-variable/noto-sans-sc
字体项目：https://github.com/notofonts/noto-cjk

字体文件保持上游原字节；未修改、重新命名或替换字体内部信息。
