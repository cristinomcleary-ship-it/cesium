# 模型与资料联动版 · 2026-10-15

本轮按已确认 Demo 接入现有 Cesium 工程，入口仍为 `?screen=management`。原有实景模型、机械倾覆演示、铁路限界立面、范围颜色与动态效果、显示分组继续使用。

## 使用顺序

1. 打开“现场工作台”，在顶部选择今日作业。已有施工计划或安全监督计划可从“导入 Excel 计划”导入。
2. 点击三维机械、防护人员，或展开右侧“现场对象”选择对象。作业选择会保留。
3. 在右侧上传或关联资料、维护人员信息、建立检查清单、填写实际检查结果、记录问题。
4. “同步记录预览”按所选作业及对象汇集当前已保存信息，可打印或另存 PDF 草稿。正式签认仍使用已有办理入口。

三个主入口为“现场工作台 / 检查与整改 / 方案与资料”。对象目录、统计、今日条件和显示设置集中在右侧。

## 上传与计划

| 内容 | 文件 | 保存及关联 |
| --- | --- | --- |
| 安全协议 | PDF | 保存原件、资料版本，可关联多个对象 |
| 施工计划、安全监督计划 | XLS / XLSX | 选择工作表与表头，核对字段及异常行后导入；保留原表、工作表、行号及未匹配机械原文 |
| 方案、机械资料、培训交底等 | PDF / DOC / DOCX | 批量上传；已有资料可增加版本，历史版本保留 |
| 营业线培训合格证书 | PDF / PNG / JPG | 与防护人员个人信息关联，保留证书原件 |

Excel 导入生成待核验作业草稿，不自动发布计划或确认施工许可。同类型、计划号和计划起始日期的重复导入会被阻止；部分失败可重试已准备的批次。无法匹配的机械不会自动创建设备或猜测对应关系。

PDF、Word 支持原件上传与关联，本轮不自动识别文件内容。PDF、图片可预览；Word 保留原件供下载查看。资料版本上传与正式发布分别办理。

## 防护人员与检查

人员档案包括姓名、所属单位、岗位、电话、证书编号、培训/发证单位、培训日期、证书载明有效期及附件。保存姓名后人物对象名称同步更新；证书上传不自动得出资格核验或到岗结论。

新清单按用户输入的适用项点建立，初始结果全部为“待检查”。检查、问题保留明确作业、对象关联及登记时对象快照。模型后续调整不改写旧记录。检查已确认后不在现场表单中改写。

资料版本可关联多个对象，日常证据按作业区分；人员证书等明确关联的长期资料可复用。未闭问题可继续进入既有核查、责任分派、整改和复核流程。

人员定位器接入及完工归档不在本轮范围；现有历史数据保留。

## 权限与更新

计划导入需要计划及文件权限。对象资料登记需要资料登记权限（或既有现场登记能力）及相应对象权限；关联已有资料需要资料、模型及文件权限。人员档案更新需要资源、模型及文件权限；证书登记还使用资料登记流程。服务器重新核验权限及记录修订。

更新包含前端和 Node 后端，不能仅把 `dist` 放入普通静态服务器。源代码包不含正式数据库、账号、附件、工程模型及 `node_modules`。

停止原服务并备份实际数据目录，将源码更新到原工程后，使用 Node.js 24：

```bash
npm ci
npm run build
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

访问 `http://127.0.0.1:5173/?screen=management`。已有端口正在运行时先停止旧进程。保留原 `CESIUM_DATA_DIR`、`CESIUM_MANAGEMENT_DATA_DIR`、`CESIUM_SPATIAL_DATA_DIR` 等配置，不能用空测试目录替代正式数据目录。

自动验证与浏览器验收记录见本目录 `20261015-validation.md`。
