# 机械配置与姿态变化过程表

## 配置机械

“施工机械”和“资源与档案 → 机械”的新增入口使用同一个配置面板。一台机械对应一个稳定的系统资源 ID，机械识别号由用户填写。

1. 点击“新增机械”，指定机械识别号，可选填机械名称。识别号在当前项目有效机械中唯一，检查时忽略大小写、首尾空格和全半角差异。
2. 选择吊机、桩机或挖机。
3. 输入该类机械的尺寸、姿态和站位。可在场景中点选位置，点选优先使用可见倾斜摄影表面。确认拾取来源与工程高程基准。
4. 选择是否管理现场传感器数据，默认“否”。选择“是”并保存后，再关联所需字段和数据来源、启用接入；仅选择“是”不会自动生成传感器数据。
5. 点击“保存机械配置”，机械身份、模型参数和管理选择一次保存。保存前取消不会创建空台账。

已有机械从“已登记机械”下拉框或场景目录的“配置”进入。修改识别号不会更换系统资源 ID，原有业务关联继续指向同一台机械。旧台账没有识别号时可以查看、删除；通过配置面板保存时需要补填。

普通资源资料更新、资格、使用与任务记录仍使用原业务流程。原有吊臂回转零度、传感器字段转换、模型连续更新及倾覆分析保持既定语义。

## 删除机械

“删除机械”以及场景显示目录中的“删除”会同步移除当前机械台账条目、三维模型和场景目录项；未布置的旧机械也可删除。该机械的当前倾覆管控定义同步停用，现场传感器更新及正在进行的姿态记录停止。

删除使用当前项目、账号权限和资源修订校验。删除失败会保留原记录并显示原因；已删除资源不能被迟到的保存请求或传感器回传恢复。

历史使用记录、任务引用、已记录的姿态和审计记录保留。关联的已确认资源到位需求转为待核对，限界、防护人员等共享对象不会随机械删除。

## 导出姿态变化过程表

点击机械配置面板顶部“姿态记录 / 导出过程表”，直接进入“姿态变化过程表与视频”区域：

1. 选定一台已保存且有有效姿态与位置的机械，点击“开始记录当前机械”。
2. 进行人工参数调整，或启用已配置的现场传感器数据。记录固定跟踪开始时的机械；切换面板选择、关闭编辑面板不会更换记录对象。
3. 点击“停止记录”。选择“当前机械”或“当前项目全部已记录机械”，按需输入北京时间范围。
4. 点击“导出姿态变化过程表（CSV）”。文件包含 UTF-8 BOM，可用 Excel 打开。

每个变化参数占一行，包含机械识别号、名称、种类、北京时间、变化前值、变化后值、单位、人工/实测/模拟来源、采样时间、来源字段以及过程说明；初始姿态单独标识。导出同时保留系统资源 ID、UTC 时间和原始数值，便于核对。

时间范围按记录时间筛选，留空表示全部已记录时段；结束时间包含所选秒。无记录或范围内无数据时不生成空过程表。旧历史中未记录的机械识别号标为“未记录”，不会用当前识别号回填历史。

记录来自模型目标姿态，人工草稿预览也属于人工变化；倾覆演示动画不作为现场实测记录。未开始记录的时段不能追溯生成。原始 JSON/CSV 导出继续保留，记录按账号和项目保存在当前浏览器，达到容量上限后停止并提示，不自动覆盖旧记录。切换项目、失去权限、暂停场景或删除记录对象会停止记录。
