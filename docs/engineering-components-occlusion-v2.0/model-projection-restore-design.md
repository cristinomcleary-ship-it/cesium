## 架构审查与技术方案

旧版 `engineeringComponents/footprints.ts`、`preciseGeometry.ts`、`preciseClipping.ts` 与相关摄影服务在当前版本仍保留。旧版对原三角面做中心投影和精确并集，由原摄影裁剪集合沿投影方向贯穿高度裁剪，并保留实际二维孔洞；它不按摄影是否进入三维实体或接触原表面判断。

当前模型行控制器负责按钮、项目与实例隔离、保存状态、构件选择、目标事务、隐藏独立、取消队列和模式切换。这部分保留。原 GLB 专用轮廓解析器要求构件标识和特定文件结构，不能用它直接替换通用模型读取能力。

实施方案是复用旧版投影、并集及精确裁剪内核，以当前 Cesium 运行时读取到的完整原三角面作为输入；保留旧解析入口用于对照验证。计算在 Worker 中进行，保持有界队列、预算、取消与失败保留。投影结果依赖完整模型世界姿态，因此位置、旋转和比例改变时撤销旧位置贡献并重新计算，拒绝迟到结果；同位置构件选择更新失败可保留仍授权的旧贡献。

真实模型验证发现，转换模型可能把大量三角面集中在少量节点，原单节点一次并集会触发 120 秒计算上限。对此采用分批精确并集与分层归并；对跨越较大范围的大节点按空间邻近关系安排处理顺序，避免每个批次横跨整条线路。保留全部原三角面、内部孔洞方向及原有整数网格精度；累计量化轮数按最长计算路径记录。不得延长超时、删减构件或简化轮廓来通过验收。优化后重新进行样板、全线、转换模型及旧版结果对照。

工程模型使用独立精确投影来源，不改变便道、临建、开挖和剖切的既有来源或参数。不得修改视频 AR 源码、源模型几何、结构、材质和数据库结构。
