# 工程模型三维接触遮挡修正：架构审查、技术设计与修改清单

## 已核实基线与需求

实际在线源码、候选起点和指定开发分支当前均为 b296997e77591b899829cb48dd2fa41ac389b86c。沿用 codex/engineering-components-occlusion-v2.0；在独立源码候选内开发，切换前保持现有运行目录。固定回退引用仍为 4239fb7709017b530e818f7a88399a89c729a4eb。

用户纠正的三个验收条件：
1. 遮挡面向所有已成功加载的工程模型，不按原始扩展名或 Jiashan 交付包哈希限制。现有普通导入接受 GLB、SKP、DWG、RVT；各转换器的可用性与是否实测独立记录，不将未验证的转换器写成已通过。成功导入后均以 Cesium Model 表示。
2. 仅裁除与实际三维实体相交或接触原模型表面的倾斜摄影。模型水平投影内但高程不接触的摄影必须保留；不得使用投影贯穿、包围盒、全模型最低/最高高程之间的柱体、凸包或自动补面代替。
3. “模型遮挡”开关位于“场景显示→工程模型”每行的“定位、调整位置、外观”之后。各模型可同时独立启用。隐藏工程模型与关闭遮挡仍是两件独立操作。

## 只读审查结论

- sceneDisplayPanel.ts 的 itemRow 负责截图中的行；main.ts 的 syncSceneDisplay 为 Model 行提供动作。SKP 导入和资料库恢复读取已保存转换产物；遮挡无需重新转换源文件。
- 当前 engineeringComponents/controller.ts 仅允许交付包原模型及单元的文件哈希，用于真实 componentId 绑定是必要校验，却不应成为通用模型遮挡的准入条件。该控制器一次只绑定一个构件树，不能拥有所有模型的遮挡生命周期。
- preciseClipping.ts 将摄影片元三维位置投到切平面，只检查二维环内点，未保留实体高度，故高架下方、上方及隧道空腔会被过度裁剪。此错误不是边界精度问题，必须更换工程遮挡的几何判定。
- 临建、便道及地表编辑共享 TemporaryWorksClippingManager。其原二维方案语义不在本次变更范围；工程三维贡献需与原贡献组合，继续使用同一所有权、暂停和地下工具租约。
- 锁定 Cesium 1.144.0 / engine 26.2.0 含运行时 ModelReader，可读取已解码顶点与索引、量化/交错属性及实例变换。运行时接口须有版本和结构守卫；不能将皮肤、形变或自定义顶点位移未经处理的原顶点冒充当前表面。

## 三维几何判定

从已就绪的 Model 读取实际绘制几何；保留源文件、拓扑、材质、节点及定位不变。读取与计算分离：预算检查和小批读取让出主线程，拓扑与 BVH 在可取消 Worker 内执行。几何缓存绑定实际实例、内容及节点/定位版本，不以文件名识别，不在每帧重读大缓冲。

在局部三维坐标中对摄影 fragment 的真实位置判定：
- 经原边连接、闭合性、退化/重复面及方向检查的实体，使用原三角面点内判定。不同实体取并集，不能用全局奇偶计数使重叠实体互相抵消。
- 同一实体的嵌套内壳和孔洞保留；不能把每个内壳独立当成实心体。区分实体与场景节点，不能假设一个节点总是一个封闭实体。
- 开口、非流形或无法证明体积的几何只贡献原表面接触，不自动封口、补厚度或制造实体。必须报告这种模式，不伪称完成体积判定。
- 数值接触容差仅补偿测得的浮点表示与运算误差；不提供未经授权的几何膨胀。CPU 计算精度、GPU 浮点误差和验收采样间距分别记录。
- BVH 包围盒只加速排除；最终裁剪依据必须是原三角面接触或经核验实体内部。全量预算、取消、超时和失败均显式处理，不截断几何或降低精度后宣称成功。

先用 A001 与 TN021 证明高度、实体与空腔行为，再验证原全线、两份实际 SKP 转换产物及格式无关的运行时输入。闭合性检查与自交检查的证据不能混称；若技术障碍影响完整几何证明，先报告原因和替代方案，不能回退为二维轮廓。

## 渲染和状态兼容

共享裁剪管理器增加显式三维贡献，组合条件为“原便道/临建等二维贡献命中，或工程三维实体/表面命中”。工程关闭时仅撤销自己的贡献。未启用三维贡献时原路径保持原样。新 GPU 准备成功后再切换，失败保持仍有效的原贡献；目标或模型位置失效时撤销过期范围。继续遵守外部所有权、AR 暂停、开挖/剖切租约，不修改视频 AR 模块。

独立模型管理器按项目、账号、模型实例管理多个贡献。行开关是模型遮挡总门；已绑定 Jiashan 构件树时有效集合为“模型总开关 AND 各构件 O”，单构件/分组/全选操作保留。不得同时叠加一份全模型贡献掩盖构件 O。关闭总开关保留细分选择；隐藏与外观变化不撤销遮挡。通用模型默认采用所有实际实体几何。

界面状态区分关闭、计算中、已生效、部分/表面模式、暂停和失败，不能只根据布尔选中显示已生效。已加载且有权访问的摄影目标统一通过现有权限边界获取；多个目标的应用须明确且可恢复。旧构件面板与新模型行入口必须共享同一状态，不能存在两个竞争开关。

个人遮挡偏好独立保存；兼容读取旧关联状态，不覆盖原显隐、定位、外观或数据库结构。删除/卸载、权限变化、项目切换、位置变更及迟到异步结果必须正确释放或恢复。新状态不默认启用到此前未配置的模型。

## 验收门槛

同一相机下检查摄影像素与实际拾取，至少覆盖：实体内/外、上方/下方同投影、斜面与凹角、交叉梁、互相重叠实体、嵌套空腔、隧道两壁与洞内、开口面、接触边界、多模型、多摄影、隐藏后遮挡、单/组/全 O、关闭后恢复、变换、刷新、删除、权限及取消。原文件计算前后哈希一致。

执行现有全量回归、构建、受影响模型/摄影/便道/临建/开挖/剖切及视频 AR 恢复验证；使用真实硬件 GPU。比较同设备/素材/视角的性能和主线程响应，记录实际预算与资源释放。未真实执行的格式或场景不得标记通过。只有全部必要验证通过后才发布实现并切换本机，逐阶段记录完整 SHA、结果与部署身份。
