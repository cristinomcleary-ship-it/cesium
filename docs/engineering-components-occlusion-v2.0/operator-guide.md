# 工程构件管理与独立遮挡

本轮直接绑定资料库中已经加载、定位的 Jiashan 重构 GLB。接入前逐字节核验模型 SHA-256，并核对交付清单与 GLB 节点；同名模型不能代替版本核验。原模型的坐标、旋转、比例、网格、材质和源文件均不重写。

## 使用

1. 在原工作台加载已有工程模型，点击地图上的“工程构件”。从“已定位模型”选择该模型，再点击“接入构件”。未配置模型包、账号无权限、模型未就绪或版本不匹配时会显示原因。
2. 先选择“A001# 墩 · 样板”或“TN021 隧道 · 样板”。查看范围只暂时隔离其他构件，不覆盖其保存状态；切回全线恢复各构件自己的状态。
3. 构件行、分组行和“当前范围”分别提供单构件、分组、全选三级操作。“显示”和“参与遮挡”是两个独立开关；分组为混合状态时显示半选。
4. 点击树中的构件选中它；“定位所选”移动相机。“三维选择”开启后，点击场景中可见的真实节点，会选择并展开树中的对应构件。隐藏构件可从树中选择，但不会成为屏幕拾取目标。按 Esc、关闭面板或进入原编辑工具会释放三维选择。
5. 展开“独立遮挡检测”，启用橙色检测面。检测面按所选构件或当前范围放置，通过“前后偏移”穿过模型，或“按当前视角放置”重新设置方向。

| 显示 | 参与遮挡 | 普通场景 | 独立检测面 |
| --- | --- | --- | --- |
| 开 | 开 | 构件正常显示 | 构件挡住其后的检测面 |
| 开 | 关 | 构件正常显示，保留原自深度 | 检测面不被该构件挡住 |
| 关 | 开 | 构件不显示 | 构件仍挡住其后的检测面 |
| 关 | 关 | 构件不显示 | 构件不挡检测面 |

独立检测与交付离线网页的颜色／独立深度／检测面语义一致。它使用单独深度缓冲；原便道、临建、摄影、开挖、剖切、地形、屏幕拾取和视频融合仍使用各自已有路径。该开关没有改写原模型融合规则，也没有新增视频 AR 遮挡规则。

参考线、参考点默认隐藏，可单独显示；它们不是实体，不能启用遮挡。全线全选针对 25,258 个实体构件；69 个参考对象单列管理。

## 状态与退出

显示、遮挡及单构件选择保存在本机浏览器，按项目、账号、资料库模型实例、资产指纹隔离。刷新后在原模型就绪时恢复绑定；进入另一个项目或账号不会套用旧状态。可导出 JSON，再在相同身份与模型版本下导入；错误版本、未知字段和超限文件会拒绝应用。

“解除接入”释放专属事件、高亮、深度缓冲并恢复接入前节点显示，不删除模型或状态文件。模型删除、项目权限撤销、页面退出也释放资源。原场景协调器暂停工程效果时，恢复原节点供既有工具使用，结束后使用当前有效状态恢复。

## 资源配置与边界

服务端环境变量 `CESIUM_ENGINEERING_ASSETS_DIR` 必须指向已核验的原交付包绝对目录。服务只读提供清单、GLB 和单元结构索引，并沿用原项目账号与模型权限。没有配置时既有工作台照常使用，工程接入提示资源未配置。

全线接入使用完整 GLB。108 个独立单元包合计仅覆盖 3,551 件实体，不能据此声称覆盖全线。A001 与 TN021 可直接绑定独立单元 GLB，也可从全线模型中隔离查看。

当前适配锁定 Cesium 1.144 / engine 26.2 的节点及绘制接口，升级依赖前必须重新运行真实 GPU 验收。检测默认关闭；全线同屏的独立深度需要处理大量实际网格，性能以本轮实测记录为准。

原包校验清单中 `Jiashan.skp` 的哈希与当前文件不一致；本轮不改写或恢复该源文件。接入依据为已经核验的重构 GLB、构件清单、单元包以及逐面几何验证结果。
