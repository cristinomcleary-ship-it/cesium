## 已发现并修复的问题

1. 转换模型的大节点一次精确并集过慢，轨道模型初次达到原 120 秒 Worker 上限。改为每批 2048 面、8 路归并；超过 131072 原三角面的节点按空间邻近安排批次。保留全部原三角、带方向孔洞及原 `1e-8 m` 整数网格。较小节点保留原排序，避免不必要的量化变化。未延长超时或减少几何。
2. 最初生产构建将条件 `new URL` 识别为普通资源，导致 Worker 被错误打包为原始 TypeScript 数据地址。生产页面测试在真实点击时捕获失败。改成两条独立静态 `new Worker(new URL(...))` 表达式，重建后同一生产测试 12/12 通过。
3. 环境适配仅使用已有模块入口、依赖与视频编码器：Playwright 动态导入改用现有 ESM 入口；Python 使用已有 openpyxl 与 UTF-8 环境；媒体测试使用当前 Edge 支持的现有编码器及 FFprobe。未修改视频 AR、原测试断言或依赖锁文件。

失败报告与后续通过报告分别保留。原地表测试的 favicon 404 和摄影失败恢复测试主动注入的 HTTP 503 均有具体记录，不宣称所有旧测试控制台为空。
