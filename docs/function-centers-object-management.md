# 六大功能中心与对象管理

基线：`24f79e0c2a62613417c61f61077949aee147c97e`（临建设施 1.1.0 基线及自动初始高度）。开发分支：`codex/function-centers-object-management-20261109`。

## 功能入口

| 中心 | 入口 |
| --- | --- |
| 数据资源中心 | 倾斜摄影、CAD 图纸、工程模型导入、GIS 数据、已保存资料 |
| 三维场景中心 | 对象目录与显示、已布置模型、标绘、地下与隐蔽工程 |
| 施工管理中心 | 临建规划、计划与进度、施工任务、资源安排、方案与资料 |
| 安全监测中心 | 施工机械、邻近营业线管控、基坑监测 |
| 巡检融合中心 | 视频 AR、巡检与取证 |
| 展示汇报中心 | 平台总览、电子沙盘、三维汇报 |

左侧按中心展开并支持关键词搜索，例如输入“便道”定位到临建规划。窄屏以“功能中心”按钮打开导航。管理/现场工作台顶部也提供六中心入口，返回工程工作台仍执行原项目、权限和草稿检查。原 `?screen=management`、`?screen=safety`、legacy 入口与独立 AR V2 链接保留。

导航移动原有 13 个按钮，保留 DOM 节点、data-tab、监听器和专业编辑器。切换复用原 Cesium Viewer。计划、任务、资源、资料与巡检快捷入口调用原管理工作台，不创建新业务表单或数据库。

## 对象操作

| 操作 | 数据影响 |
| --- | --- |
| 隐藏/显示 | 保留对象和资料，通过现有个人显示偏好调整场景 |
| 图层移出场景 | 仅卸载本次运行的对象；保留资料库记录、原件、对象编号、显示分组，可重新载入 |
| 资料库删除资料 | 明确提示删除平台保存的记录与文件副本及引用影响，沿用原删除权限与确认 |
| 机械删除 | 沿用原机械删除命令，确认台账、模型、当前管控配置的影响，历史业务记录保留 |
| 临建配置/删除 | 复用原方案编号、专业编辑器和删除确认，保留自动初始高度逻辑 |
| 基坑/监测点/标绘配置 | 按选中编号打开已有对象，不另建记录，不自动移动镜头 |

“移出场景”是当前会话操作，重新打开平台仍按原规则自动恢复资料；它不是长期禁用自动加载。对象暂时卸载时保留其分组，明确删除才清理相应成员。

机械资源详情将“机械配置”和“台账资料”区分：配置进入同一机械编辑器，台账资料维护资格、状态等业务属性。沙盘场布、进度和风险说明仍保留各自已有编号及数据，界面明确其展示用途；不按名称自动合并到正式任务或临建方案。

## 编辑与失败处理

- 临建有未保存编辑、预览、取点或计算时，离开前确认；取消保持草稿。保存或删除进行中拒绝切换。
- 模型放置、标绘/重绘/贴图、基坑取点过程中阻止跳到其他编辑器，显示完成或取消提示。
- 目录配置先核验目标存在及可访问，再切换并选中同一记录；异步导航按有效请求顺序处理。
- 主动项目切换执行草稿检查，权限撤销强制清除失去授权的预览。既有浏览器存储模块的项目能力范围不扩大。
- 基坑读数、阈值、布点、支撑及 CSV 保存失败时恢复原内存记录、保留表单输入，不显示成功，可重试。
