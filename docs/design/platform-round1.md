## 范围与兼容边界

本轮交付两组可独立审查的修改：

1. 基础整改：私有缓存访问边界、诊断访问与资源预算、摄影挂载真实路径边界、登录限速、显式 HTTPS Cookie、附件并发内存预算；取消离页清理、影像/视频恢复仲裁、模型异步提交复核和标绘连续应用。
2. 场景切换：薄效果协调器，旧开挖/剖切的效果暂停恢复、精确解绑和完整销毁；休眠 AR 状态刷新不得取消地表任务；恢复路径宽树保护和异常租约回滚。

本轮不改变摄影/工程模型的原始文件、模型放置默认值、采样阈值、Cesium 版本和业务数据 schema。摄影位置编辑、独立工程遮挡、四类几何编辑中心与全息结构库按后续轮次开发。本轮不将这些未来功能标记为已支持。

LYR/可选 Python 服务治理、转换成功未认领目录回收、地表接边精度以及新 shader 的多通道兼容问题仍在专项清单中。本轮优先处理会阻断场景切换和必要访问保护的问题，不以未实现功能代替旧功能回归。

## 场景协调

保留两套 AR 的 `VideoOverlaySceneIsolation`、现有 `TemporaryWorksClippingManager`、精确借用清理与锁定引擎 shader guard。新增协调器只管理已注册效果的嵌套暂停租约和恢复顺序，不接管全部业务状态，不增加每帧轮询。

旧开挖几何保持原有参数语义。直接迁入新 polygon contributor 会额外引入范围/拓扑限制，因此本轮采用按目标的 owner 暂停租约：旧效果接管前暂停该目标的受管贡献；关闭并解除精确绑定后恢复受管贡献。未知外部 owner 继续受到保护，不能为了新效果销毁外部集合。

暂停保留用户意图；退出根据当前有效配置重新建立资源，不挂回可能已经被 Cesium setter 销毁的集合。嵌套租约、失败回滚、销毁后释放、暂停时修改参数、删除目标和切换上下文均需要测试。

旧地下工具继续采用原有的全局、未持久化草稿语义。切换项目不清空用户绘制的锚点，也不把旧草稿改为项目存储；只重新筛选当前有权访问的载入对象并释放失效目标。新地表工具仍保留自身项目作用域。裁剪管理器的旧模块销毁不连带销毁独立 scope；清理链会继续处理其他资源并汇总异常。

## 验证与交付

- `npm test`：原全量 Node 回归入口，不缩减原测试集合。
- `npm run test:cpu`：模型放置与 AR 缓存/权限独立回归。
- `npm run test:tools`：四组工具测试；先按工具子项目锁文件安装依赖。
- `npm run test:python`：两套 Python 合成测试；环境由 `tools/ci/python-requirements.txt` 或已有兼容虚拟环境提供。
- `npm run build`：TypeScript 和 Vite 生产构建。
- 新增及既有浏览器、真实模型和硬件测试单独记录；不能以 CI/CPU 成功代替。

每组修改独立提交，最终记录准确交付 SHA、实测结果和待本机项。本机 Codex 只负责环境、部署、真实验证与日志反馈，产品缺陷返回 GPT 修改；不自行重构或扩展开发。

不创建本机备份，不复制生产数据测试，不清空 IndexedDB/OPFS。候选默认使用隔离测试数据根；正式切换保留原访问 origin、数据根和启动入口。具体见本轮部署任务书。
