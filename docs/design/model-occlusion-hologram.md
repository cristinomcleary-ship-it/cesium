# 工程模型遮挡与结构全息投影

开发基线 `4239fb7709017b530e818f7a88399a89c729a4eb`，Cesium 1.144.0。第二轮的真实模型与硬件 GPU 验收由本机按部署任务书核实。

## 工程模型遮挡

工程模型使用资料库记录 ID。作为独立模型导入的墩柱、承台等构件可分别设置。场景显示的分组入口用于批量调整工程模型成员的遮挡设置，原分组显示开关继续操作显示。

个人遮挡设置按项目和账号保存。CC 方案记录与工程对象关联的独立遮挡规则，打开已保存方案时使用其保存值。未包含该字段的旧方案继续使用原渲染与缓存逻辑。已启用的遮挡规则涉及渲染输出，因此应进入原有缓存比较流程，标注数据仍由原独立层维护。

CC 复用现有资源协调和临时场景接管。工程遮挡从已授权、已加载的网格取深度，使用当前方案中的变换。退出、资源卸载、账号变更与浏览器页面销毁都需恢复场景对象并清理临时渲染。测试要覆盖两个重叠模型、隐藏的遮挡源、旧实景遮挡并用、方案保存与还原、缓存变化及权限边界。

| CC 显示 | 工程遮挡 | 渲染行为 |
| --- | --- | --- |
| 勾选 | 开启或继承 | 原模型颜色和深度参与融合。 |
| 取消勾选 | 开启 | 使用 GLB 三角网写入遮挡深度，保留源材质的透明裁剪。 |
| 勾选 | 关闭 | 使用同一视频帧和镜头畸变绘制模型颜色，与普通叠加重叠的位置由普通叠加优先显示。 |
| 取消勾选 | 关闭或继承 | 模型退出当前融合帧。 |

只显示颜色的模型依然接受实景和深度源遮挡。只有遇到颜色独立的规则才增加第二次场景取帧。DJI 旧回放继续走既有深度和场景流程。整份 GLB 内的任意子网格遮挡及遮挡几何编辑属于后续模型显示编辑中心范围。

## 结构全息投影

工程模型面板提供明确的全息拾取入口。通过工程模型记录 ID 和配置中的唯一 GLB 节点名匹配结构；单体模型也可以作为整体绑定。使用工程模型局部坐标或指定 WGS84 锚点定位全息 GLB。投影按需加载单个预览实例，支持旋转、缩放和打开原交互网页。工具切换、资源删除或权限变化应取消拾取并释放实例。

Node 服务从 `CESIUM_STRUCTURE_LIBRARY_DIR` 读取本机目录内的结构目录、独立预览 GLB 和原网页文件。入口使用既有管理账号授权。网页以受隔离的方式运行，保留包内相对路径的静态资源。各电脑提供同一套目录规范，源工程模型、现场资源和业务数据继续由原有系统管理。

用合成工程 GLB、投影 GLB 和原交互网页测试真实地图拾取、锚点、控件和网页互动。原开挖、剖切、模型编辑、摄影位置调整、临建与 AR 回放继续走原测试入口。
