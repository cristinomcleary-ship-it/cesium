# 设计便道、场地硬化与临建亮度

日期：2026-11-06。

该实现分支用于 Draft 代码审阅与隔离验证，不是已经验收的正式部署版本。真实倾斜摄影、真实模型 GPU 外观和用户电脑性能验收尚未完成；自动化测试及生产构建不能代替这些检查。执行命令、测试数量、失败项与跳过项以[本轮测试报告](test-results-designed-surfaces.md)为准，本说明不重复登记测试数量。

## 便道

新便道采用用户指定的起点路面顶椭球高、路宽和结构厚度。工程标高必须先按项目已确认的关系换算，不能直接当作椭球高。

- 未开启分段纵坡时，全线采用起点路面顶标高，纵坡为 0%。保留的坡段草稿不参与计算，也不阻止平坡生成。
- 开启纵坡后，坡段必须连续覆盖完整 CAD 里程。系统按真实里程及原有弧长因子计算连续高程；反向里程同步交换起终点、反转坡段和坡号，保持原空间形状。
- 硬化层、处理层由路面顶向下生成。现阶段新设计道路采用竖直结构边侧；不自动生成填土、挡墙或任意深度的封边。
- 生成路径不调用摄影高程采样器，不建立第二摄影取样场景，不计算土方。返回的采样数量为 0，不能把设计高程称为摄影实测值。
- 复用既有中心线、弯道联合、里程及网格分区机制；显示网格由路线和设计断点决定，不沿摄影细碎网格逐三角面加密。

摄影遮挡使用完整道路实际占地的外轮廓及孔洞，不采用全线包围矩形，不为每个路面三角形创建裁剪对象。摄影裁剪不能保证道路两侧与未知地面无缝接顺；用户仍需通过标高、纵坡及范围调整处理明显高差，并从侧面检查。

旧逐点贴地便道和旧土方便道按原数据读取，保留原网格、标高语义和历史指标。旧记录不会在打开页面、调整亮度或切换显示时批量重新求解。需要采用新设计方式时，另存新方案，原记录继续保留。

## 场地硬化

临建类型增加“场地硬化”。用户填写固定参考点、场地顶椭球高和水泥层厚度，再用矩形或多边形圈定范围。默认水平；可设置坡向和坡率。绘制位置来自鼠标射线与设计平面的交点，树冠、屋面和水面不决定场地标高。

源选区、永久保留区和派生显示面分别保留。顶面、底面与必要侧面构成水泥层；纹理通过材质表达，不通过面积密集采样或加密网格实现。

### 重叠处理

摄影遮挡与新地面排重是两套配合的规则：前者合并同一摄影图层各所有者的有效遮挡贡献，后者决定同一区域实际显示哪一份水泥面。

|重叠对象|处理|
|---|---|
|便道|保持便道几何和纵坡，硬化按便道实际结构占地避让|
|驻地、钢筋场|避让已明确确认的实际地坪或基础，不用整个模型包围盒、屋顶轮廓推断地坪|
|其他硬化|按持久化优先顺序分配显示区域，不依赖加载顺序；不合并或覆盖源记录|
|不同标高或坡面|沿实际接界核对高程，提示调整标高、坡度、拆分区域或明确保留高差；不自动拉平既有对象|
|完全被覆盖|保留源记录并标注被覆盖，不生成重复地面；上层退出后可以恢复|

GLB 的随设施避让区必须确认轮廓、地坪顶标高和厚度，并绑定对象、放置变换及资源内容版本。模型替换或轮廓关联失效后重新确认，不能继续套用旧资源的地坪判断。模型范围未知时阻止将其当作无冲突成果保存。

永久保留区与随设施避让区分开：花坛等永久保留区不会因设施删除而补回；随设施避让区则在设施隐藏、移走或删除后重新计算。用户确认的高差处理绑定当前依赖状态，依赖发生相关变化后重新校验。

同一位置的顶面和共面侧壁按实际交界排重，不以抬高几毫米、关闭深度检测或改变绘制顺序掩盖闪烁。二维避让并不自动生成道路过渡面、台阶、填方或挡墙；“明确保留高差”不能标记为“已经无缝接顺”。

### 显示与恢复

仅关闭摄影遮挡时，对象继续显示并参与地面排重；隐藏、删除或首次加载未就绪时，不能新占据下层硬化的显示区域。硬化自身遮挡来自已就绪的实际显示面，扣除永久保留区和当前避让区。

每个对象独立拥有其遮挡，撤销一个对象不撤销其他对象的贡献。发现外部功能占用不兼容裁剪接口时报告阻断状态，保留外部裁剪集合及数据。

硬化自身编辑失败或取消时恢复原有效状态。便道或 GLB 的正常移动、显隐、删除触发硬化重算失败时，原对象操作仍可完成；仅暂停受影响硬化区域及其自有遮挡，保留源参数并提示重新生成。影响范围包含变化前后区域；无法可靠局部拆分时暂停整个受影响硬化对象。未就绪的补回地面不能先遮住摄影留下空洞，过期 Worker 结果不能覆盖新状态。

## 临建亮度

统一亮度为 50%～200%，默认 100%；对象可沿用统一值或使用独立的绝对百分比，不与统一值相乘。默认值表示当前代码的展示照明基准，尚不能称为已在用户电脑和真实模型上完成视觉校准。

照明只作用于临建 GLB，保留 Cesium PBR 对金属/粗糙度、Specular/Glossiness、纹理、透明度及法线的处理。单个模型采用固定局部主光与中性补光，并停用自身太阳阴影和动态环境贡献；不修改 Viewer 的时钟、场景灯光、曝光、摄影和机械参数。颜色仍由 Cesium 进行一次正常的色调映射和颜色空间转换。

滑条只更新模型已有着色阶段的 uniform，不重新下载、解码或重建 GLB，不重建裁剪。独立宣传墙的附加文字平面也只更新材质亮度参数，不随拖动重绘画布或上传新纹理。普通界面注记不受此滑条影响。

亮度按本浏览器、本项目独立保存；偏好模块可由宿主传入用户标识进一步隔离，但当前界面不宣称跨设备或跨账号同步。统一亮度在操作完成后保存；对象编辑中的亮度可单独保存，无需重新生成或搬运模型网格。取消未保存编辑恢复原偏好，存储失败必须提示，不能报告已经保存。

## 性能边界

道路与硬化的主要几何计算在 Worker 中执行，结果用结构化参数及可转移的数值缓冲区传递。取消、切换项目或更新任务会停止旧任务，过期结果不进入场景。浏览器没有 Worker 时，只允许受限的小规模回退，不把大任务同步压到界面线程。

硬化使用空间索引筛选邻居和接界，编辑只更新确实受影响的区域；不逐帧重算全场布尔运算，不重载未变化的 GLB，不重新求解整条相邻便道。

当前代码设有独立工作量保护：

|范围|保护条件|
|---|---|
|设计便道输出|最多 50000 顶点、100000 三角面|
|硬化源边界|最多 4096 点|
|硬化参与边界与相邻对象|总输入边界最多 20000 点、最多 512 个占地区域对象|
|硬化相邻表面与输出|相邻表面最多 100000 三角面；输出最多 50000 点、100000 三角面及 2048 个区域|
|硬化高差核对|限制接界求交次数，并限制局部坐标范围|
|新设计面的摄影裁剪适配|分别限制边界点、含孔分解后的多边形和拓扑核验工作量，超限保留摄影并报告原因|

这些是防止失控的计算预算，不是已经测得的帧率保证，也不是设计精度。超限不能截断道路、填掉孔洞或扩大遮挡后报告成功。真实场景仍须对帧时间、响应、取消和资源回收进行同机固定基线对比。

## 回退

需要临时停止新增显示时，可先使用临建总开关暂停新增临建及其自有遮挡，保留方案数据。不能为恢复摄影而清空全局裁剪，也不能删除其他模块的数据。

正式回退前另存当前完整数据与私有资源快照，再使用已经核验的旧发布目录和与旧版兼容的数据副本恢复服务。新版硬化与设计便道记录须单独保留；旧程序未必理解新对象类型，不能直接要求旧版本解释新记录，更不能批量删除或改写它们来消除错误。

不要直接恢复整套旧业务数据库覆盖升级后的其他业务更新。涉及数据版本差异时，在独立副本核对并保留增量，再执行明确的恢复步骤。回退后复核原入口、图层和业务状态，确认本功能的资源及遮挡已正确释放。禁止通过清空浏览器全部存储来处理版本问题。
