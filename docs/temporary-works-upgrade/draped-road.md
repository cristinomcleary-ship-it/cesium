# 贴地便道算法与验证范围

`solveDrapedRoad` 为新建便道提供独立的贴地求解路径。原设计纵坡求解器和旧方案网格保留，可继续读取、显示和删除。新算法不调用土方积分，也不产生挖方或填方数量。

## 高程与几何

对于每个有效顶点，按同一摄影模型返回的真实采样高程 `H` 生成：

| 顶点层 | 高程 |
| --- | --- |
| 地基处理底面 `formationHeight` | `H` |
| 地基处理顶面 `baseHeight` | `H + treatmentDepth` |
| 硬化层顶面 `surfaceHeight` | `H + treatmentDepth + hardeningDepth` |

厚度是竖向厚度，三层共用平面三角网。新结构的侧边竖直；旧方案中的设计标高、纵坡、边坡宽度不参与新贴地求解。CAD 的原始方向、曲线里程修正系数、分段里程与弯道轮廓并集沿用原模块。弯道不会重复铺设重叠面。

## 缺测、陡坎与有限采样

- 有效基础网格间距为 `min(输入间距, 1 m, 半路宽)`，沿原中心线与横断面布置。
- 所有渲染底面顶点必须具有独立的摄影采样值。缺测值不使用临近值、地形值或设计高程替代。
- 对每个候选三角形额外采样三条边中点和内部重心。默认最多加密 3 层；共用边同时拆分，防止相邻三角形出现 T 形接缝。
- 任一角点、边中点或重心缺测的三角形剔除。采样 rise/run 大于 1（默认 45°）的三角形作为陡坎剔除。上述阈值可通过求解参数设置。
- 如果摄影探针高于三角形底面超过 `0.00001 m` 数值误差阈值，则加密或剔除该三角形，绝不整体抬高底面。若探针低于底面的间隙大于 `0.02 m`（默认表面贴合容差），同样加密或剔除。
- 返回缺测、陡坎、未收敛三角形数、舍弃面积、实际采样间距、采样点数及保留面最大探针偏差。界面应展示这些结果；没有有效面时不得保存为成功方案。
- 默认上限为 50 万个唯一采样位置，单次采样请求最多 512 点。达到上限返回明确错误，不降采样、不填补高程。

有限采样不能证明任意两个探针之间不存在更小的摄影突起或空洞。上述容差针对实际采样位置，不是对整片摄影表面的无限分辨率保证。现场验收应结合真实摄影分辨率、陡坎及空洞检查；未通过的局部区域作为缺口保留，不能以模型抬高来掩盖。

## 自动化验证

独立测试命令：

```sh
node --experimental-transform-types --import ./tools/test-module-loader.mjs --test src/temporaryWorksDrapedRoad.test.ts src/temporaryWorksRoad.test.ts src/temporaryWorksBends.test.ts src/temporaryWorksRoadCoverage.test.ts
```

2026-11-05 执行结果：32 项通过，0 失败。其中新增 10 项覆盖纵横坡与实际层厚、直角转弯、155° 急弯并集、起终点和内部缺测、顶点未命中但内部探针发现的摄影孔洞、竖直陡坎、摄影突起、CAD 曲线里程及反向、零厚度与全缺测、错误采样及取消。既有 22 项设计道路回归通过。

单元测试不代替生产构建的 Cesium 浏览器实际场景验收。本文件只记录算法级证据。
