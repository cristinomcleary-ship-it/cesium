## 本次补齐

关闭摄影遮挡时可按输入坐标独立布置模型；独立宣传墙不强制依赖摄影。开启建筑摄影遮挡仍要求关联摄影图层。道路只读取新贴地模式所需参数，旧隐藏坡度/坡高不再影响创建，断面示意更新为处理层底面贴摄影、侧边竖直。

公开代码不含新增模型、贴图、LOGO、实际几何 manifest、资产几何审计或预览图。运行资源及详细尺寸/锚点记录在私有交付包内，通过安装器接入，步骤见 [部署与回退](deployment.md)。资源校验通过不构成现场验收。

## 亮度、立体文字与自动布置修正

模型使用独立主光、环境亮度及中性漫反射填充，不改变摄影或其他模型的全局曝光。私有资源按完整源文件及逐节点几何哈希验证后，清除已确认的旧单位/旧项目立体字和 Logo，新增中铁二十四局/中国铁建精确文字。公开脚本只包含通用处理逻辑，实际源节点映射和预览图保持私有。

项目部和钢筋棚新增“按图纸轮廓自动布置”：以结构底面计算位置、方向与长宽，保留高度；180°反转、覆盖率、逐底面摄影采样摘要随方案保存。旧方案默认手动模式，不静默重新布置。详见[自动布置说明](auto-placement.md)。

取得的真实 DWG 未能确认目标设施完整闭合轮廓，且单位存在冲突，因此没有声称完成用户项目的自动落位验收。离线模型图不代替真实 Cesium 场景；本机部署和最终视觉验收仍需使用原工程资料。
