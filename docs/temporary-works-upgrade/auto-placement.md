# 驻地与钢筋厂按图纸自动布置

项目部和钢筋棚可选择已完成坐标配准的 CAD 闭合轮廓，点击“按图纸轮廓自动布置”。程序使用私有模型清单中核验过的结构底面，计算位置、平面朝向及 X/Y 缩放；模型高度保持原值。这里的轮廓应是该设施的设计范围，而不是整个工地的外界。

## 图纸与尺寸

先在 CAD 导入中核对单位、坐标系、轴顺序及控制点，再选择对应设施的闭合轮廓。图纸头信息的单位与实际绘图单位可能不同，程序不据此静默重写坐标配置。开口折线、退化轮廓或不能容纳模型的轮廓会提示错误。

矩形轮廓自动匹配朝向与长宽，默认预留 0.05 米边界余量。所用尺寸来自结构底面，不包含树木、旗杆、屋檐等外包范围；表单中的模型长宽仍表示整个模型经过缩放后的包络。底面锚点偏离结构轮廓中心时会同时补偿位置。

不规则轮廓搜索能容纳完整模型底面的可行位置，并显示覆盖率。长宽缩放不能把一栋矩形建筑变成任意凹多边形；结果不保证最大覆盖。程序检查整条边线，防止端点在界内而边线跨越凹口。朝向有两种相反可能时，可使用 180° 反转后重新生成。

## 摄影落位

选定倾斜摄影图层后，在隔离的摄影场景中沿建筑底面边线和内部取样，避免采到预览模型或已有临建。每个独立底面分别要求至少 3 点且至少 80% 的采样有效才接受自动取高。底面采用最高有效摄影高程，以免在已采样点嵌入；同时展示有效点数和高差。

该策略不能识别摄影中的树木、车辆等地物，也不能保证未采样处没有突起。建筑底面保持水平，高差较大时低处可能悬空，应在真实场景中复核并用实测椭球高调整。未选择摄影时仅完成平面适配，不代表已经落地。

## 保存与修改

保存包括实际位置、旋转、尺寸、布置模式和可选的拟合/采样摘要。旧方案缺少模式字段时按手动方式恢复，不会自动重新缩放。手动修改位置或尺寸后转为手动布置，后续生成使用输入值。重新选择自动布置会根据所选轮廓重新计算。

模型材质照明只影响临建 GLB，不改变其他场景模型、摄影或全局曝光。替换私有资源后刷新页面，资源清单不使用 HTTP 缓存；本机运行目录中的 GLB URL 带清单内容哈希，避免继续命中旧模型。

## 验收边界

计算测试、模型文件审计与离线图均不替代用户电脑上的浏览器验收。需要在原项目中检查：正确设施轮廓、实际尺寸与朝向、摄影高程、品牌文字的每个可见面、明暗、保存刷新恢复以及摄影遮挡开关。
