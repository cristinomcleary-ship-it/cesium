# 机械场景联动、连续姿态与导出

## 资源与场景目录

“创建台账”后，该机械立即进入“场景显示 → 施工机械”，未设置模型及位置时显示“尚未布置”，可进入配置。保存姿态后，同一条资源更新为已布置，可以显隐和定位。移除三维实例保留资源配置入口；删除资源、切换项目或失去权限时移出当前目录。

显隐属于当前账号的个人显示偏好。更新尺寸、保存资源及接收传感器数据不会反向打开已隐藏的机械。没有变化的目录刷新不重复重建列表或应用显示设置。

## 机械放置与角度

“在场景中点选位置”优先拾取当前可见、已加载的倾斜摄影表面，其次为工程模型；机械自身、倾覆范围、CAD 和标绘覆盖物不作为倾斜摄影的落点。没有命中模型时才退回地形或参考椭球，面板明确显示实际拾取来源。位置仍是 WGS84 经纬度与椭球高。

吊机原编辑器的数字输入、滑块、15°微调、“吊臂回正”、传感器初始角及回传值均采用同一约定：**吊臂背离车头，并与车身纵轴共线时为 0°，俯视顺时针为正**。

| 整机方位 | 吊臂相对角 | 吊臂指向 |
|---|---|---|
| 0°（车头向北） | 0° | 南 |
| 90°（车头向东） | 0° | 西 |
| 0°（车头向北） | 180° | 北，即车头方向 |

原资源台账继续保存模型源坐标角。当前吊机的界面 0°对应内部源角约 60.79949°，转换仅发生在界面/接口边界。打开旧记录不会改变其实际姿态，修改其他参数也不会偷偷回正吊臂。旧记录缺少回转字段时仍恢复原始模型姿态。

## 连续姿态显示

同一机械资产在实时更新时复用同一个 Entity、ModelGraphics、GLB 和着色器。臂长、支腿、桩机高度、仰角、回转等通过参数和矩阵更新，不再逐包生成及替换模型文件。源几何变形、保存快照与倾覆计算仍使用原有几何定义。

传感器姿态默认按 350 毫秒平滑过渡，回转跨越 359°/0°时取最短弧；新数据从当前显示姿态继续过渡。过渡从实际动画帧开始计时，慢帧会延长显示过渡，避免忙碌期间直接跳到目标。仅有变化且可见的机械参与过渡，完成、隐藏、暂停、切项目或销毁后释放动画调度。倾覆计算使用最新有效目标姿态，不为等待视觉过渡而延后更新。

## 姿态记录

1. 在机械编辑器选中机械，展开“姿态记录与视频 → 机械姿态记录”。
2. 点击“开始记录当前机械”。首次记录完整初始姿态，此后只记录有实际变化的参数。
3. 手动修改有效姿态或启用传感器模拟。关闭编辑器、选择另一台机械后，记录仍跟踪开始时的机械；停止、切项目/账号、失去权限、移除模型或更换机型时结束记录。
4. 点击“停止记录”，再导出 JSON 或 CSV。清空前可先导出；导出不会删除原记录。

记录包含记录时刻的 UTC、浏览器本地时间与时区、机械 ID、字段、单位、前后值、人工/模拟/实测来源。遥测采样时间逐字段取自实际报文；未回传字段不会得到虚构采样时间。描述例如“2026-10-29 10:30:00 吊机：吊臂伸长至38 m”只是格式示例，实际记录使用真实时钟。

JSON 保留完整数值及来源信息；CSV 带 UTF-8 BOM，可用 Excel 打开。记录保存在当前账号、项目对应的浏览器存储，刷新可恢复历史，但不会自动继续录制。每 50 条分块写入，避免每次变化同步重写全部历史。最多 10,000 条；达到上限或浏览器存储不足时停止并提示，已有记录不自动轮换删除。存储失败时应在关闭页面前导出内存中的记录。

## 带场景的机械姿态视频

展开“姿态记录与视频”，选择当前视角或机械预设视角、格式和最长时长，再点击“开始录像”。当前视角可在开始前拖动场景调整。录制范围是现有三维画布中的机械、倾斜摄影、地形及已显示的场景对象；不录制侧栏界面或音轨。

点击开始后，先等待相机与模型就绪，再准备真实场景首帧并等待编码器确认；两个准备阶段各自最多等待 20 秒，均可取消。出现“正在录制”后才开始所选时长计时。首帧准备较慢不会耗尽短片时长。录制期间可手动调整机械或运行传感器模拟。点击“结束并生成视频”后会提交最终场景帧，再生成可下载文件；生成等待最多 8 秒。达到所选时长会自动结束并保留下载结果。默认使用 WebM；只有浏览器实际支持时才可选 MP4，不会只更改扩展名。

最长 120 秒、最大 128 MiB。保持页面在前台、窗口画幅不变。切换机械、关闭编辑器、切项目、失去权限或显卡上下文丢失会取消当前录像并提示；未开始录像时没有编码、场景复制或录制定时器。

## 倾覆动画视频与工程

1. 打开“邻近营业线管控”，选择机械，点击“按角度查看范围”。
2. 设置倾覆方向，选择当前视角、侧视、斜俯视或顶视。“应用视角”可以先检查取景。
3. 点击“生成视频 + 工程”。平台确认录入 0°初始画面后才开始播放，录到 90°，等最终姿态与范围进入画面并提交末帧后封装文件。
4. 分别点击“下载视频”和“下载配套工程”。也可独立“导出动画工程JSON”。
5. “导入工程重播”在同一项目按保存的机械快照、相机和方向重播，不覆盖当前机械台账。

视频直接包含可见场景。工程 JSON 保存冻结机械姿态、支承参数、倾覆方向与速度、相机、显示设置和场景资源引用，**不嵌入完整倾斜摄影、地形或影像文件**。重播需加载原项目对应资源；项目、机械或场景引用不匹配时明确拒绝。工程不保存资源 URL 或访问令牌。

生成动画视频时临时锁定相机输入，完成或取消后恢复。机械姿态或场景资源改变会取消该次导出，避免视频与工程快照不一致。已有倾覆几何和动画算法保持不变。

## 验证与更新

相关测试覆盖目录生命周期、权限和项目隔离、模型表面优先拾取、旧角度兼容、所有源顶点的实时变形等价性、平滑与清理、姿态记录存储/导出、视频资源释放及动画工程校验。

2026-10-29 验证结果：

- 35 个相关测试文件、291 项自动测试通过；生产构建通过。
- 原有传感器工作流 8 项浏览器回归通过，停用后无继续轮询、无多余 Viewer。
- 完整平台 6 项验收通过：测试摄影表面高程拾取为 58.000014 米；资源即时入目录；实时模型对象保持一致并有中间姿态；记录、视频下载、倾覆视角与工程重播成功，重播未改写台账。
- 独立场景录像 4 项验证通过：WebM 与浏览器实际支持的 MP4 均解码为非黑场景画面，首尾画面变化；取消后无剩余录制循环。
- 吊机、桩机、挖机完成真实 GPU 显示与拾取检查。完整平台导出的倾覆 WebM 也已解码抽查首末帧，包含场景与倾覆姿态变化。
