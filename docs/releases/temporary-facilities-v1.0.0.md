# 临建设施1.0

临建设施模块版本：**1.0.0**。标签：`temporary-facilities-v1.0.0`。发布日期：2026-11-07。发布渠道：**预览版（Pre-release）**。

本版本保存当前设计便道、场地硬化与临建亮度调节的预览源码及本机修复。模块采用独立版本号；平台已有 `v1.2.0` 与历史 `1.0` 标签保留。

## 功能与操作

- **场地硬化**：进入“临建规划 → 临建类型 → 场地硬化”，填写参考点场地顶椭球高、水泥层厚度，可设置坡向和坡率；用“矩形框选”或“多边形圈选”定义范围，生成预览后保存方案。
- **设计便道**：沿 CAD 中心线使用明确的路面顶标高和可选分段纵坡，处理层与硬化层向下生成；支持路线反向、预览、取消及保存恢复，设计路线生成不依赖摄影逐点取高。
- **场地占地与摄影遮挡**：按实际网格避让便道、已确认的设施地坪及其他硬化面，保留源范围与永久孔洞；摄影遮挡、场地排重和显隐分别管理。未知地坪或未确认高差会阻止相关操作。
- **临建亮度**：驻地、钢筋棚和宣传设施支持 50%～200% 统一亮度及单模型亮度，独立保存，无需重载模型或改变其他图层的全局光照。

## 本轮修复

- 修复设计便道占地边界简化导致边界偏离实际显示网格的问题。
- 修复矩形硬化与已保存设计便道重叠时的多边形裁剪异常，保留原共享端点与真实三角面覆盖。
- 保留剖切更新的逐帧调度、外部裁剪所有权与销毁恢复修复。
- 修复隔离验证页合成地面的瓦片遍历，并补充相关回归测试。

## 验证与限制

- 本次发布工作区的 TypeScript 检查与 Vite 构建通过；构建存在已有的大文件体积提示。生成的主入口与本机预览版一致。
- 主回归共 1433 项：1429 通过、3 失败、1 跳过；退出码 1。三项失败与此前候选验证一致：资料归档 put/delete 测试缺少相应函数，私有资源符号链接测试受 Windows EPERM 限制；没有新增失败，不能称全部测试通过。
- 合成预览专项 9/9、剖面调度专项 6/6 通过，两组退出码均为 0；这些专项与主套件可能重叠，不相加为总通过数。
- 公开发布源码的功能文件与当前本机候选逐项一致；发布提交基于已公开父提交重新整理，仅增加模块版本元数据、使用入口和本说明，不包含本机整合提交链。详细运行日志与现场验证材料保留本机。

本版仍是预览：现场控制高程、坐标和单位基准、驻地与钢筋场的正确设计外轮廓需要结合项目资料确认；完整现场重叠、故障恢复和性能验收尚未完成。已有界面冒烟确认了设计标高输入、矩形框选、多边形圈选和预览按钮可用，不代表现场工程验收。

本机预览使用独立数据副本与浏览器来源，其保存的方案不会自动同步到原平台。不要把旧数据库覆盖到新增业务数据上；切换或回退版本前保留数据副本。

## 安装与发布范围

将本标签源码下载或克隆到新的独立目录。使用 Node.js 24+ 和 pnpm，在该目录运行：

```powershell
pnpm install --frozen-lockfile

# 三个数据根均使用这个新目录内的数据，不指向原平台资料目录。
$env:CESIUM_DATA_DIR = Join-Path $PWD 'project-data'
$env:CESIUM_MANAGEMENT_DATA_DIR = $env:CESIUM_DATA_DIR
$env:CESIUM_SAFETY_DATA_DIR = $env:CESIUM_DATA_DIR

pnpm run build
pnpm exec vite preview --host 127.0.0.1 --port 5289 --strictPort
```

打开 `http://127.0.0.1:5289/`。该端口须空闲；完整平台需要上述 Vite 预览服务提供本地业务 API，不能只用普通静态网页服务替代。本机已安装的预览入口继续使用原有独立数据副本，无需照此重新建立空项目。

若需要真实驻地、钢筋棚和宣传设施，应在构建前按[私有资源安装与检查流程](../temporary-works-upgrade/deployment.md)将已有、已审查的运行资源包安装到 `public/models/temporary-works`，执行 `node tools/install-temporary-works-assets.mjs --check` 后再构建。GitHub 源码包不附送这些私有模型，也不重新转换原始模型。

GitHub 提供源码、锁文件、测试、模块版本信息及本说明。私有模型和贴图、现场 CAD/摄影、真实坐标与资源映射、业务数据库、浏览器数据、个人桌面配置和本机验收产物均不随此版本上传；私有模型需按项目既有安装流程单独提供。本次不合并原草稿 PR，也不替换现用正式服务。
