## 本版修复

- SKP 后台导入从实际源码安装目录读取转换器配置及工具；模型缓存仍在原服务工作目录。配置文件中的 SDK 路径优先于环境变量，使用独立 SketchUp C API，不启动 SketchUp 桌面。
- 原运行包装的导入接口拦截已解除。启动与停止入口继续使用原平台的端口、数据目录及 Node。
- 场景目录与旧图层移除入口统一执行持久删除，覆盖模型、CAD、GIS、3D Tiles。确认删除后清除资料记录、平台文件副本及场景对象；取消或服务失败时保留原对象。
- 从资料库删除后，同步清除显示分组和显隐偏好的残留引用。异步删除跨项目或账号时，只清理发起时的作用域。
- 隐藏、临时卸载、关闭视频回放及业务附件解除保持原有语义。后端已有删除标记和拒绝旧页面写回机制保持不变。
