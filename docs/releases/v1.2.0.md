# v1.2.0 — 临建设施实景布置

发布日期：2026-11-02。

将当前已在本机生产服务验收的工程发布为 v1.2.0，包含此前平台能力及本轮临建规划系列更新。

## 功能

- 在倾斜摄影主场景生成钢筋加工场与项目驻地，支持标准模型、CAD 建筑轮廓和仅硬化场坪三种布置方式。
- 标准钢筋场包含厂房、围护、门区、堆料及设备；驻地包含办公楼、宿舍、门卫、国旗台和停车区，并带中铁二十四局企业标识。
- 旧硬化场坪可在原方案记录上补建标准模型，保留场界、网格、工程量及显隐状态；覆盖不足时保留原方案并显示原因。
- 施工便道支持弯道、分段纵坡、交换方向和分批采样。CAD 中心线全长保留，缺测区显示虚线，实体与土方仅计入有效摄影覆盖。
- 支持 CGCS2000 高斯坐标、工程独立坐标、两点定位与模型平面偏差核对；支持起点缺测时的高程校准。
- 方案可保存、刷新恢复、定位、显隐，并纳入场景显示目录；保留计算结果长文本排版修复。

## 验证

- TypeScript 检查及 Vite 生产构建通过。
- 211 项 CAD、临建规划及场景相关自动化测试全部通过。
- 在实际生产页面完成 8 项验收：版本与资源核对、三种模式切换、驻地与钢筋场生成/显隐/保存、旧场坪补建、刷新恢复、独立定位显示、小场地补建失败保护。
- 包内独立摄影示例验证两类设施保存恢复及几何位置；另回归完整 CAD 覆盖、坐标换算、分段纵坡与参考模型。

验收使用合成摄影表面与示例图纸；现场图纸的坐标、高程和对位仍以项目测量资料核对。

## 使用与兼容

进入“临建规划”，选择摄影模型、设施类型和闭合场界，核对坐标、标高及断面参数后生成模型。标准模板为 48 × 30 米，可等比缩放至 65%～100%，至少需要 31.2 × 19.5 米连续有效场坪；也可选 CAD 建筑轮廓模式。

保留现有方案存储版本，无数据库结构迁移。建筑用于三维展示，场坪工程量继续按有效网格计算。

本次发布包含源码、测试、使用说明及示例 DXF；本机工程数据、账号配置、缓存、构建输出和验收运行产物不纳入 Git。未创建本地备份。
