# v1.2.2 实际运行包装参考

这些文件逐字节复制自已部署并验证的 `output/current-version`，供审计和恢复时适配。它们不是通用安装器，不能直接覆盖现有机器的启动器。

- `server.mjs`：从独立 release 目录加载应用源码和构建；保持原 5289、工作目录与业务数据根。转换器根仍指向原安装目录，保留原 SDK/转换器配置优先级。
- `start.ps1`：核验真实源码提交与构建哈希，串行化桌面启动并复用已验证服务；保留权限接口就绪检查。
- `stop.ps1`：按 PID、创建时间、命令行、源码和数据根核实服务后停止，保留项目数据。

对应应用提交：`84300b4dedccc3f0116f03332c3ada914da95485`。对应构建 index.html SHA-256：`53a2d2f0eaa1249c473416f7e699466eca31210cfb031cddfa605e88e7b170d7`。

实际机器的桌面入口继续调用原根目录的启动/停止入口。这里不含 service.json、server-identity.json、data-preparation.json、数据库、浏览器缓存或项目资料；这些是本机运行状态，不能复制回去覆盖当前数据。

从本备份恢复时，先准备独立源码与构建，再按实际目标适配路径和身份；保留原数据、账号权限、SDK 与私有模型。失败时只回退代码、构建及启动身份。
