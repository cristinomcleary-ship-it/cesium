# 临建设施 1.1.0：位置调整与硬化自动避让

模块版本：**1.1.0**。标签：`temporary-facilities-v1.1.0`。发布日期：2026-11-08。发布渠道：**预览版（Pre-release）**。

本版保存已完成本机部署和 Chrome WebGL 验收的应用源码。驻地、钢筋场、便道、硬化均支持统一位置调整；硬化自动扣除已有设施占地，并随设施移动重新计算。

应用源码基准为 `ad74683468bc4dec26008ac2ad3ab2c783d00068`，包含功能提交 `5435622aa1f601a454517460c58937b4d723e32c` 及本机修复。发布提交只在该基准上更新本说明、README 和模块版本元数据，运行代码、依赖及锁文件保持一致。平台版本继续为 `1.2.0`；临建设施模块独立编号，历史标签保留。

## 功能变化

- 四类已保存设施提供“位置调整”，支持地图方向和视角方向、独立平移与升降步长、连续累计移动、恢复原位、取消和 Esc。
- 保存更新原方案编号，不重复创建；保存后可立即重新调整，刷新及关闭浏览器后重开保持新位置。重新编辑已移动便道保留移动后的 CAD 锚点。
- 硬化自动识别驻地、钢筋场、便道及其他硬化的真实占地，无需逐个手动排除；保留永久保留区，重复重叠只扣一次。
- 设施移动后原占地补回、新占地扣除；取消预览、隐藏与恢复、删除后重新计算。关闭摄影遮挡仍保留占地关系。
- 修复方案保存完成后“位置调整/编辑/删除”按钮未恢复可用的问题，并覆盖保存成功、失败两条路径。
- 修复 Windows 验证工具的路径匹配和 Cesium 静态资源 junction 路径解析；补充目录 junction 安全检查。

## 使用与部署

在“临建规划”的已保存方案中选择“位置调整”，设置方向及步长后平移或升降，检查硬化联动预览，再保存。取消或 Esc 放弃此次位移。

新安装使用 Node.js 24+ 和 pnpm，执行 `pnpm install --frozen-lockfile`。真实 GLB 运行资源按[私有资源安装流程](../temporary-works-upgrade/deployment.md)单独安装并校验，再运行 `pnpm run build`。完整平台使用 Vite 本地服务接口，不能以普通静态文件服务器替代。

现有工程升级前应备份代码差异、构建、配置、业务数据库和浏览器方案，使用独立工作区验证；更新时保留原 URL 的主机名和端口、原认证配置及三个数据根。回退恢复代码与构建，不以旧数据库覆盖更新期间产生的数据。

本次公开发布包含应用源码、测试、版本信息和说明。私有 GLB/贴图、现场 CAD/摄影、数据库、浏览器资料、密钥、本机启动器定制和现场截图不在发布包中；它们仍保留在原机器。发布不合并既有草稿 PR，不移动旧版本标签。

## 已知边界

自动避让不代表建筑地坪已经接顺。整体位移不重新采样摄影，历史土方不能当作新位置的计算结果；现场坐标、高程、邻接高差仍需按项目资料复核。部分周边街道底图可能显示数据不可用占位，本地摄影加载正常。该版本沿用模块预览版渠道。
