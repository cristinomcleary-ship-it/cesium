# 临建设施位置调整与自动硬化避让

适用基础：`codex/release-temporary-facilities-v1.0.0`，提交 `bd9eefee27a03f481a7b45caeeea5473a8f581d4`。

## 位置调整

1. 在“临建规划 → 已保存方案”找到驻地、钢筋加工场、施工便道或场地硬化，点击“位置调整”。
2. 设置平移步长和升降步长。默认分别为 1 m、0.1 m，可输入 0.01～1000 m。
3. 点击前后左右按钮平移，点击“升高 / 降低”调整标高。默认按相机朝向操作，也可选择地图方向（上北下南）。
4. 核对预览后点击“保存位置”。“取消调整”或 Esc 恢复原方案；“恢复调整前位置”清零本次偏移并保留调整面板。

调整后保留形状、坡度、厚度及原方案编号。CAD 定位参数随便道更新；真实模型切换为手动定位，后续编辑不会自动回到原 CAD 适配位置。调整过程不重新读取摄影高程，历史土方停止作为当前结果显示。累计平移与升降分别限制在 10 km 内，此功能用于局部位置调整。

## 场地硬化

输入场地标高和厚度，矩形框选或多边形圈选范围，生成预览即可自动排除已显示、已加载设施占用的区域，无须逐个点选驻地或钢筋场。

- 驻地、钢筋场使用模型清单中的真实底面轮廓，保留轮廓中的庭院孔洞；不以整个包围框替代占地。
- 便道和已有硬化使用已生成的实际覆盖范围，重复重叠仅扣除一次。
- 设施平移、隐藏、删除或恢复显示后，邻近硬化自动重算占用范围；永久保留区持续保留。
- 需要额外避让建筑外的已确认地坪时，可展开“补充设施地坪避让范围（可选）”填写；已有手动方案继续兼容。
- 自动排除建筑占地不代表已确认建筑地坪标高。与便道或其他已知地面存在高差时，仍需进入硬化编辑核对；便道升降后可能触发邻接硬化的高差复核。

关闭摄影遮挡不会释放设施占地；隐藏设施会释放占地。独立宣传墙继续沿用既有规则，不作为场地硬化的自动地坪避让对象。

运行 `node tools/run-temporary-works-regression.mjs related`、`node node_modules/typescript/bin/tsc --noEmit` 和 `npm run build`。
