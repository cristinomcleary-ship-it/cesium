# 视频 AR：倾斜摄影投影与同名点配准

适用于 DJI 视频和 SRT 导出的轨迹 JSON。原始视频、轨迹和模型不被修改；校正参数保存在该视频的项目资料记录中。

## 操作

1. 打开“视频 AR”，加载或恢复对应视频。
2. 展开“投影配准校正”，点击“显示倾斜摄影并启用三维投影”。模型必须覆盖视频中的建筑。也可在“投影表面”选择“倾斜摄影模型（保留楼体）”。
3. 暂停在地物清晰的一帧，点击“冻结当前帧，开始选点”。视频与地图可分别放大，地图仍可旋转。
4. 先点击视频中的固定地物，再点击模型中同一个位置。屋顶点对应屋顶，地面点对应地面。至少四对，建议六至十对，分散到画面四周并包括不同高度。
5. 点击“求解并应用校准”。系统检查误差及点的分布；错误或退化匹配不会应用。成功后保存东、北、高度以及偏航、俯仰、横滚修正，并固定选点时使用的高度基准，避免更换地形后漂移。
6. 在其他时间点复核。开始播放、拖动时间或更换参数/视频会取消未完成的选点，避免跨帧应用。

## 效果与边界

三维模式按场景深度把视频映射到屋顶和立面，使用视频相机的深度通道检查遮挡，不生成铺在地面的建筑立面。无有效深度的区域保持原模型显示。地形和平面模式仍用于只有地面覆盖的资料。

同名点校准修正相机位置和姿态；镜头内参保持冻结帧使用的值。若整幅仍存在系统性边缘误差，应使用该相机和视频分辨率的实际镜头标定值。SRT 等效焦距和绝对高度未必等于精确内参或椭球高，不能承诺仅凭 SRT 自动达到测量级精度。

场景模型应先加载清楚。投影只能反映模型中存在的几何；模型缺失的建筑、新增建筑及采集后变化无法由一段二维视频自动重建。


首次切换三维模式，或视频相机移入新的区域时，会先加载该视角内的模型瓦片；遮挡数据未就绪时保留原模型画面。

## 开发验证

Cesium 固定为 1.144.0；源相机深度通道的私有接口集中在 `src/videoArModelProjector.ts`。升级 Cesium 时必须重新运行模型 GPU 回归。

- `tools/verify-video-ar.cjs`：实际视频解码、帧同步、暂停选点、换源隔离、保存与重启恢复。
- `tools/verify-video-ar-controls.cjs`：真实模型屋顶深度拾取、六点配准和过期配对拒绝。
- `tools/verify-video-ar-model.cjs`：屋顶/立面像素对应、遮挡、观察角变化、滚转/内参变化、移除与销毁。

浏览器测试使用独立端口与临时资料目录，不修改实际工程资料。`PLAYWRIGHT_MODULE` 可指定本机 Playwright 安装目录。

## 本轮验证范围

已通过 55 项算法/资料库测试、13 项主应用浏览器检查、6 项同名点交互检查、9 项模型 GPU 检查，以及当前工程 SSE1 模型精度下的真实影像帧投影检查。

真实 HEVC 视频在无头测试浏览器中不支持解码，因此真实影像检查使用 FFmpeg 从原视频提取的同一时刻帧；完整播放、拖动和帧同步使用可解码的视频夹具验证。真实资料的两个诊断高度均未作为校准值保存。

复杂细碎表面仍可能有覆盖空洞，保持原模型颜色。当前版本没有完成用户场景的实测同名点校准，不能把渲染检查通过等同于地理位置已经精确对齐。
