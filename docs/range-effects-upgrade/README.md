# 范围动态效果、倾覆扫掠外包与定位接入

适用仓库：`cristinomcleary-ship-it/cesium`，分支：`codex/machinery-integration-20261013`。

## 范围显示效果

在右侧“邻近营业线管控 → 显示效果”中选择类别，展开“范围动态效果”。六类范围分别保存颜色与效果：防护责任区、人员工作区、安全限界、倾覆范围、侵限相交区、计算支承区。

| 效果 | 显示方式 |
| --- | --- |
| 静态 | 保持所选颜色与原有填充、边线显示。默认使用此效果。 |
| 呼吸 | 范围明暗周期变化，不改变边界坐标。 |
| 流动 | 明暗条带沿范围流动；机械投影的轮廓和空隙保持原位。 |

速度为 0.25–3 倍，强度为 0–100%；强度为 0 时呈静态。设置按浏览器、账号和项目保存，兼容已有配色与分组偏好。“恢复默认”会恢复本模块全部显示设置。

动画由材质完成，不逐帧重算模型、投影或业务结果。隐藏范围、停用项目或关闭页面标签时停止对应的刷新请求；仍有可见动态范围时继续显示。速度是显示倍率，实际节奏会受设备渲染帧率影响。

填充透明度沿用既有规则，动态效果只调制原有透明度，不将透明填充重新变成不透明。轮廓及风险高亮仍保留各自的显示强度。动画与人员越界状态无关，报警仍通过定位点、状态文字和汇总提示表达。

## 默认倾覆范围如何绘制

默认全方向范围直接使用当前机械模型计算的扫掠外包，和侵限筛查共用同一多边形。它不以“站位中心 + 一个统一最大半径”生成圆。

计算使用当前完整模型的顶点、尺寸、构件姿态、朝向及地面支承。对每个倾覆方向，模型绕该方向的支承线从 0° 旋转到 90°；解析求出顶点水平投影的端点和极值，再形成全方向保守外包。倾角不再使用各顶点独立落地、可能超过 90° 的推算。

方向采用 360 个样本，并保留未采样方向的外扩余量；切向分条和最终凸包也会扩大轮廓。因此这个范围是模型几何筛查外包，不是事故实测边界。高耸、近对称的机械全方向外包仍可能自然接近圆形；不会为了形状差异人为制造凹凸边界。

“按角度查看范围”继续提供当前方向、当前倾角的完整三角网格投影，保留显示精度可分辨的凹口和孔隙。可以切换为“投影 + 保守外包”对照：前者表示当前姿态占地，后者覆盖假设条件下的全方向倾覆过程。风险汇总使用后者。

固定支承线和水平地面是假设；几何续转不处理首次接触后的停止、滑移、构件变形、解体、吊载和地基变化。贴附现场模型的显示方式不会自动将计算改为坡面动力学。

## 人员定位器

本版本补齐通用鉴权 HTTP 上报接口和页面自动读取。设备厂家协议、坐标转换与实际硬件联调仍需结合设备资料完成。

接入链路：定位器 → 厂家平台或现场网关 → 平台定位接口 → 已绑定人员 → 工作区越界判定。

详细配置、请求模板、返回码和现场核对步骤见 [定位器接入说明](定位器接入说明.md)。页面“防护人员 → 人员定位监测 → 如何接入现场定位器”也提供操作提示。

服务器保存每台设备的最新实测点，浏览器每 2 秒读取一次；服务器重启后等待设备重新上报。页面关闭后不执行页面越界判断，当前没有短信、声光、设备振动联动和轨迹历史。没有新位置时会按已保存的过期时限显示定位过期，不将离线当作在岗。

验证记录见本目录 `validation.md`。部署须应用源码、构建并重启含后端的项目服务，保留既有数据库、资料、模型和账号。
