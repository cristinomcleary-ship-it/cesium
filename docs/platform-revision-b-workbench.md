# B 批工作台与交互验收

本批基于 A 提交 `4a2f4426d28209ef89035745e7c3c6d518eec034` 增量实现；六模块、原 Viewer、原件服务和 SQLite 命令接口继续使用。没有数据迁移。

## 接入位置

- `src/managementStudio.ts`、`management/forms.ts`：工点工作台、按名称搜索关联、资料反向关联、整改回合/证据、上传进度、同账号会话内草稿恢复、保存后异步统计不重开旧抽屉、模态焦点、移动更多入口。
- `src/management/workpointRelations.ts`：只对服务端已授权快照建立工点与任务、资料、检验、巡检、问题的关联，不通过任意 ID 扩大读取。
- `src/managementStudio.css`、`managementWorkspace.css`：浅色管理/深色三维、统一变量、可读字号和响应式；无选中对象隐藏右栏。
- `src/management/photoComparison.ts/.css`：同源授权原照片全屏并排与滑块、同步缩放和平移、人工标注带证据进入问题草稿，并由同一问题命令独立存储归一原图坐标及原件SHA；修改问题描述不覆盖标注。未核验拍摄日期明确为空，归档时间单独显示；不同视角不声称配准。
- `src/management/ganttView.ts/.css`：真实周/月日期刻度和今日线、各任务最近批准基线与当前计划双轨、真实日期偏移。拖动仅预览，确认继续走原带 revision 命令。
- `src/managementWorkspace.ts`：已有 Viewer 的只读监听/视频计数诊断。

## 草稿与文件

文字草稿仅在当前浏览器会话、项目、账号分区缓存；密码/账号创建表单不缓存。刷新后由用户点击恢复，不自动提交。原文件不会复制入浏览器缓存，刷新恢复时须重新选择文件；同页面上传失败保留文件及文字可重试。换账号清除当前未提交缓存并重新请求授权快照。解除关联走 `link.remove`，不删除原文件。409保留输入并显示当前服务端修订，需核对后再次保存。

## 回退

本批无 schema 迁移。使用 `git revert <B提交>`，保留 A 的服务端可靠性修复和业务数据。照片对比/Gantt不写原片或批准基线；当前计划只有明确保存才更新。
