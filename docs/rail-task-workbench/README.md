# 任务管控总览与机械风险处置

本版本在现有邻近营业线平台上增加任务总览、机械配置缺项提示和机械风险处置入口，沿用已有任务、机械资源、限界和问题台账。本轮不增加人员定位接入、定位轨迹或定位告警功能。

## 1. 按任务组织现场配置

进入“邻近营业线管控”，右侧新增“对象配置 / 任务总览 / 风险处置”三个入口。

1. 在“项目统筹平台 → 计划进度 → 任务”建立任务，填写负责人、计划日期，并按既有流程发布或办理。
2. 在“对象配置”选择机械、防护人员或安全限界，设置“关联施工任务”并保存。
3. 在“任务总览”选择该任务，查看涉及机械、已保存配置、待绑定配置、防护人员、专属限界、共用候选限界和未闭环风险单。人员工作区域随防护人员配置归属任务。
4. 机械可通过已保存的管控配置、人员负责机械、资源本身的任务关联或未取消的资源调配记录纳入任务总览。因此同一台机械可以涉及多个任务，各任务数量不可直接相加。
5. 未保存管控配置或尚未放置模型的机械仍会显示；“配置机械管控”可以进入原编辑器。已有配置表示绑定已保存，不代表参数完整、具备开工条件或安全通过。

共用限界单列为候选，必须在每台机械配置中明确勾选；归入任务不会自动选择限界。无配置机械若还未关联任务，会显示于“全部可见数据”和“未关联可见任务”；在资源调配中指向任务后，可在该任务下发现缺项。

任务筛选只改变右侧列表，**不会隐藏场景对象、缩小筛查输入或停止其他机械的侵限判断**。已完成、已取消任务也不会自动解除机械筛查。原任务不再可见时显示提示，不自动切换到全部任务。

“任务管理 / 任务详情”打开现有任务页面，不另建一套进度台账。“导出任务汇总 CSV”下载当前账号可见的全部任务汇总，含导出时间、任务日期、配置缺项和未闭环数量；各行不能相加。

## 2. 将机械筛查结果登记为处置单

在“对象配置”的机械筛查结果，或“任务总览”的机械卡片中，对“潜在侵限 / 接触边界”选择“登记处置”。

- 仅允许登记当前已保存的机械、管控配置、所选限界及任务版本。草稿预览、正在计算或缺失来源的结果不能登记。
- 初始状态为“待核查”，表示人工登记的浏览器几何筛查线索。服务端检查来源、权限、版本和字段一致性，并不重新计算模型，也不确认真实事故会发生。
- 登记时保存机械模型姿态、管控定义、限界多边形、任务信息、筛查关系、捕获时间和来源版本。以后修改模型不会改写该单的历史快照。
- 同一机械、限界和任务已有未闭环单据时，界面提供原单入口；服务器也拒绝重复登记。删除重建机械管控配置不能绕过去重。
- 已关闭、已核查为误报或重复的单据归档后，如果当前配置仍出现风险，可以显式登记新一轮。不因网页刷新、任务切换或模型动画自动建立单据。
- 登记、关闭单据都不改变当前几何筛查结果，也不自动确认施工任务完成或阻断完工。

## 3. 办理与历史追溯

进入“风险处置”，按任务及“未闭环 / 全部 / 已关闭或归档”筛选。点击“查看 / 办理处置单”，进入已有问题台账流程：

**待核查 → 核查并指派整改 → 开始整改 → 提交整改复核 → 通过并关闭。**

复核不通过会退回整改。初次核查可以明确记录误报或重复依据。指派人员、期限、整改说明、复核意见和操作历史沿用原台账；证据附件仍通过原流程上传。处置单详情新增“登记时的机械筛查快照”。

历史来源更新或移除后，风险列表提示来源变化，保留登记时依据。“定位当前机械”飞到当前模型站位，不重放事故或恢复旧模型。“已关闭”是处置流程结论，不代表当前模型一定与限界分离。

## 权限与数据

任务总览使用服务器当前账号可见数据。风险登记需要模型查看和现场填报权限；指派、整改、复核继续执行原有权限和修订冲突检查。现有任务范围受限账号不授予模型查看权限的策略保持不变；无模型权限时不下发机械几何快照，仍可按任务权限办理可见问题。

处置单、快照和审计保存在现有管理数据库中，刷新和服务重启后保留。界面显隐、动画和任务筛选不写入业务数据。该版本不增加后台自动几何报警、短信、声光联动、传感器接入或轨迹回放。

部署时应用源码补丁、构建并重启包含后端的原服务，保留原数据库、账号、模型、上传目录和环境变量。具体测试证据见本目录 `validation.md`。
