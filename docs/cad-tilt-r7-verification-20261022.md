# R7 整体倾角与贴附高程验证

版本：`2026.10.22-R7-group-tilt-surface`。在目标分支的 `e83e5527f42dcb77037c393039802ed18d455f83` 基础上修复，没有覆盖原工作区或资料。R6 的单对象测试不足以证明整体调整和贴附路径正确；本次分别补充真实入口回归。

## 实际修复

- 去掉整体模式的倾角禁用，新增独立 `groupAdjustment`。全部 CAD／工程模型以持久化共同中心应用 `G × L_i`，显示选择不改变整体范围；倾斜摄影参照不跟随。
- 整体两轴、平移、航向、倾角归零、重置、撤销／重做、保存重开、诊断、标绘与缓存同步。整体旋转后单对象画面拖动补偿旋转，保持请求的世界方向。
- 贴地／贴模型 CAD 在地图接收表面隐藏前采样，创建保留表面高程的临时副本，不再强制使用原图纸 Z。缺失覆盖显式失败，取消及时恢复可见性；绝对高程与已采样实体保留原有几何。
- 普通 GLB 依附导入／恢复去掉 2000 点总预算，全部顶点分批、全部成功后写回；排除 CAD／GIS 和地球。失败保留源文件与资料库。
- 接收模型即使未作为视频叠加显示，其定位变化也使贴附 CAD 缓存失效。未修改源视频分辨率／时间轴或播放进度条样式。

修复前的新浏览器测试确实在“整体 heading 控件必须可用”处失败；修复后通过。实际表面测试使用源端点高差 20m 的 CAD，22 个加密点在椭球分支约为 0m，在水平 3D Tiles 分支为 99.999345–100.000610m（目标 100m）。将已显示模型移动到 CAD 范围之外后明确失败，未回退源 Z 或地球。

缓存测试生成 18 帧 640×360、15fps 视频，核验源时间戳；从缓存播放直接修改整体倾角后旧缓存失效，重建后的解码像素哈希改变。连续进入退出五次：地图位置恢复误差为 0，方向分量误差小于 2.2e-9，真实鼠标平移、滚轮缩放、拾取均可用，资源计数不递增，残留帧回调为 0。浏览器、加载和渲染错误为空。

证据在 `docs/cad-tilt-acceptance/r7/`，可重复脚本为 `tools/verify-video-overlay-cad-tilt.mjs` 和 `tools/verify-video-overlay-surface.mjs`。前者覆盖真实控制器但使用绝对高程合成 CAD，后者覆盖真实贴附几何路径；两者边界不同。其后对单对象拖动补偿和隐藏接收模型缓存依赖的补充改动，已由对应真实方法回归测试和最终构建覆盖。
