## Windows PowerShell 示例
按本机真实仓库路径修改变量。目标 worktree 目录必须不存在：

```powershell
$projectRoot = 'F:\codex\cesium'
Set-Location -LiteralPath $projectRoot
git status --short --branch
git worktree list
git rev-parse HEAD
git fetch origin codex/platform-management-v2

$worktree = 'F:\codex\cesium-platform-management-v2'
if (Test-Path $worktree) { throw "目标目录已存在，请先检查，不覆盖：$worktree" }
git worktree add --track -b codex/platform-management-v2 $worktree origin/codex/platform-management-v2

Set-Location -LiteralPath $worktree
git rev-parse HEAD
git merge-base --is-ancestor 24f79e0c2a62613417c61f61077949aee147c97e HEAD
if ($LASTEXITCODE -ne 0) { throw '分支不包含指定基线，停止执行' }
git status --short --branch
```

如果本机已有同名分支，先用 git branch -vv 和 git worktree list 检查，不删除或重置。实际工程路径不同则替换路径。
