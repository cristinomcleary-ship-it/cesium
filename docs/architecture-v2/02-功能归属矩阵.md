## 归属冲突裁决
1. 按业务数据权威写入者确定归属，不按当前代码文件位置确定。
2. 一个对象可在多个中心显示，但只有一个权威编辑入口。
3. 跨中心入口是快捷操作/引用，不得复制表单和数据。
4. 任务、机械、临建、基坑、视频证据以稳定 ID 关联。
5. 删除默认归档/软删除；原始资源删除前检查引用。
6. 场景显隐偏好不能覆盖业务对象状态。
7. 安全分析可读取机械姿态，但不得拥有第二份机械参数主记录。
8. 基坑监测专业系统可由 Cesium 启动/投影，监测读数仍由专业监测服务负责。
