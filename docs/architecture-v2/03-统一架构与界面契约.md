# 03 统一架构与界面契约

## 目标布局
- 顶部全局栏：项目切换、全局搜索、消息/告警、账号权限、系统设置。
- 左侧主导航：六大功能中心，展开二级菜单；支持收缩。
- 中央：当前唯一 Cesium Viewer；场景选择、绘制、测量由原场景宿主管理。
- 右侧：统一业务面板容器；同一时刻一个主活动面板，可有受控子视图/抽屉。
- 底部状态栏：项目/数据连接、模型加载、实时数据状态、当前坐标、性能状态。

## 响应式尺寸建议
| 视口 | 顶栏 | 左栏 | 右栏 | 约束 |
|---|---:|---:|---:|---|
| 1920×1080 | 60px | 220px | 380px | 三维视口保持主导 |
| 1366×768 | 56px | 190px | 340px | 两侧可收缩 |
| 1024 以下 | 56px | 抽屉 | 抽屉 | 不强行维持三栏 |
尺寸为设计目标，需浏览器实测调整；面板切换不得销毁 Viewer。

## 导航注册契约（草案）
```ts
type PlatformModuleId =
  | "engineering" | "project" | "safety"
  | "construction" | "monitoring" | "inspection";

type PlatformModuleDefinition = {
  id: PlatformModuleId;
  title: string;
  icon: string;
  order: number;
  children: PlatformNavigationItem[];
  requiredPermissions?: string[];
};

type PlatformNavigationItem = {
  id: string;
  title: string;
  panelId?: string;
  actionId?: string;
  children?: PlatformNavigationItem[];
  requiredPermissions?: string[];
};

type PlatformPanelContext = {
  projectId: string;
  actorId?: string;
  permissions: readonly string[];
  viewer: Cesium.Viewer; // 只引用宿主已有实例，禁止模块 new Viewer
  sceneDirectory: SceneDirectoryApi;
  openPanel: (panelId: string, args?: unknown) => void;
};
```
这是接口草案，不得直接替代现有类型。Codex 必须先对照真实构造器、权限模型和 Viewer 所有权设计兼容适配层。

## 面板生命周期
1. 导航切换不销毁 Viewer。
2. 打开面板复用现有实例；若惰性创建，必须有单实例注册与销毁规则。
3. 隐藏/卸载 DOM 不等于销毁业务对象或清除场景数据。
4. 关闭面板释放监听器、定时器、Worker、临时资源；业务保存只由显式保存流程完成。
5. 切换项目前保护未保存草稿，切换后不得带入旧项目对象。
6. 权限撤销立即关闭不可访问面板并停止实时订阅。
7. 场景选中与业务选中保持可追溯同步，避免循环事件。
8. Escape、关闭、刷新遵守草稿保护。

## 统一面板视觉结构
标题/面包屑；业务摘要（可选）；页签/分类折叠；搜索筛选；对象列表；详情编辑；固定操作区；状态和错误提示。不得在每个面板重复建设全局搜索、项目选择、场景目录或通用告警中心。

## 场景目录
业务视图按六大中心和业务类别组织；场景视图按对象类型组织。两种视图映射同一对象 ID 和场景实例，不复制记录。按能力提供显隐、定位、属性、唯一权威编辑入口、卸载实例、删除/归档影响确认。

## 全局快捷工具
坐标拾取、测量、空间标绘、图层显示、模型诊断、场景质量检查属于上下文工具，由全局场景工具栏和专业面板提供，不作为与六大中心平级的一级导航。

## 视觉交互
- 工程工作台风格，避免过度装饰和大面积仪表盘卡片。
- 中央场景优先，面板内容密度适中。
- 表单分类折叠，默认只展开当前必要步骤。
- 重要操作位置统一，删除与危险操作明确区分。
- 无数据显示真实空状态，不补造演示业务数据。
- 统计数字必须绑定真实数据。
- 异步操作有加载、成功、失败、取消状态。
