# 04 数据对象与生命周期设计

## 核心实体边界
| 实体 | 主键建议 | 权威职责 | 不承担的职责 |
|---|---|---|---|
| Project | projectId | 项目、坐标/高程基准、项目状态 | 场景实例显隐 |
| ResourceAsset | assetId | 原始文件、格式、哈希、版本、存储位置 | 项目中的摆放状态 |
| BusinessObject | objectId | 机械/临建/基坑/任务等业务身份和参数 | 原始文件字节、个人显隐 |
| SceneInstance | instanceId | Viewer 实例、变换、图层、显隐 | 权威业务属性 |
| Relation | relationId | 对象间任务、区域、资料、设备关联 | 复制被关联对象 |
| TelemetryBinding | bindingId | 设备身份、协议、数据源、对象关联 | 成为机械主记录 |
| TelemetrySample | sampleId/源序号 | 采样值、时间、质量、来源 | 未校验业务结论 |
| BusinessEvent | eventId | 风险、告警、检查、整改及审计 | 替代源对象状态 |
| Evidence | evidenceId | 原始证据、来源、哈希、时间、关联对象 | 自动证明验收通过 |

以上为概念模型，不代表立刻建立同名数据库表。第一阶段必须映射到当前真实存储：SQLite 管理库、项目资料库、IndexedDB 临建方案存储、场景显示偏好及专业存储。

## 当前已知存储边界
- 项目管理：README 说明管理后端使用 Node.js 24 内置 SQLite，默认 project-data/management.sqlite，附件 management-files/；可由 CESIUM_MANAGEMENT_DATA_DIR / CESIUM_DATA_DIR 配置。
- 临建设施：temporaryWorksStore.ts 使用 IndexedDB plans，按 projectId 查询。
- 场景显示：SceneDisplayStore 保存项目/用户范围显示偏好和自定义分组。
- 机械/安全：管理 API、业务类型和服务端 Gateway 处理项目记录、权限和设备数据，实际权威表需逐项确认。
- CAD、模型、视频、GIS：存在项目资料库持久化及场景加载状态；原件、缓存和实例边界需逐模块核对。

## 身份规则
1. 业务对象有稳定 ID，不用显示名称作为关联键。
2. 场景实例 ID 与业务对象 ID 分离；一个对象可有多个明确关联的场景表现。
3. 资源文件 ID 与业务对象 ID 分离；资源可被多个场景实例引用。
4. 机械对象由施工机械台账权威管理；安全模块通过 resourceId 引用。
5. 临建设施方案 ID 与场景实例分离，编辑保存不得无意创建重复方案。
6. 基坑、监测点、监测样本保留父子与时间来源关系。
7. 视频、航迹、抽帧、标定和证据保留原始来源与时间标识。
8. 跨项目引用必须明确授权。

## 生命周期操作
| 操作 | 影响范围 | 默认保护 |
|---|---|---|
| 显示/隐藏 | 当前用户视图偏好 | 不改业务状态 |
| 定位 | Viewer 相机 | 不改数据 |
| 编辑属性 | 权威业务对象 | 修订号/权限校验 |
| 卸载实例 | 当前场景实例 | 保留资源与业务对象 |
| 删除实例 | 场景实例记录 | 检查业务引用 |
| 归档对象 | 业务状态 | 保留历史与审计 |
| 删除业务对象 | 业务对象及允许级联项 | 默认软删除并列引用 |
| 删除原始资源 | 文件及存储副本 | 被引用时阻止或先解除引用 |
| 删除项目 | 全项目数据 | 备份、确认、授权 |

## 一致性与事件
- 显示偏好与服务端业务状态分开。
- 服务端命令执行身份、项目、权限和修订号校验。
- 删除后场景渲染层收到明确对象移除事件。
- 异步加载取消时释放临时 Viewer 资源，不删除已保存原件。
- 监测数据携带采样时间、来源、质量；过期/断连/无效不得伪装正常。
- 安全分析记录输入对象版本、姿态时间、限界版本、计算时间和结果状态。
- 迁移可检测、可回滚；兼容期旧记录仍可读取。
