## 旧入口必须映射
原始工作台顶部入口包括：平台总览、电子沙盘、CAD 图纸、工程模型、临建规划、施工机械、邻近营业线管控、倾斜摄影、GIS 数据、视频 AR、标绘、基坑监测、3维汇报；另有现场工作台、AR V2 独立页面。

Codex 必须逐项建立“旧入口 → 新一级中心 → 新二级菜单 → 原实现适配器 → 权限 → 数据归属”映射，不能遗漏 query screen、快捷按钮、右侧工作区、弹窗、隐藏入口和独立 URL。
