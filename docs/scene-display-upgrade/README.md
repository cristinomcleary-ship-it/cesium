## 铁路设备安全限界立面

进入“邻近营业线管控”，在右侧“参数编辑”选中“安全限界”。“显示效果 → 安全限界”新增三种形式：平面、立面墙、平面＋立面墙。

- 墙高可在 0.5–100 米之间调整，默认 5 米。
- 墙面透明度为 0–100%；0% 不透明，100% 墙面完全透明，轮廓仍保留。默认透明度 78%。
- 墙底沿已绘制的各顶点高程，顶部逐点向上增加墙高，保留坡度；它不是自动贴合每一处模型起伏的采样墙。
- 原有配置仍默认平面显示。展示偏好立即生效，按当前浏览器、项目及账号记忆，无需保存业务配置。

墙高与透明度仅用于显示，既有侵限筛查仍采用平面几何口径，不会因墙体看上去较矮或较透明而减少潜在侵限数量。

## 三台机械只露出两台的原因

截图右侧汇总已经显示 3 台，原左侧列表受最高 270px 和 `overflow:hidden` 限制，第三行被裁切，无法滚动到达。不存在按机械类型合并或丢失实例的问题。

右侧新的“施工机械”分类逐台列出不同资源 ID，包括同类型的多台机械，显示“当前显示数 / 总数”，目录可以滚动和搜索。原有已放置机械、台账设备和潜在侵限的统计含义不变：未布置模型的设备仍可进入台账统计和待核实，不会为了凑齐数字而被排除。

## 一个右侧工作区

工作台右侧分为“场景显示”和“参数编辑”。顶部功能菜单仍进入原有导入、机械、标绘、基坑及营业线管控编辑器；关闭业务编辑器仍保留原草稿检查。切换右侧两个入口只切换视图，未保存内容保持在原编辑器中。

显示目录按类型列出：实景模型、工程模型、CAD、GIS、施工机械、标绘对象、防护人员、防护责任区、人员工作区、铁路安全限界、机械倾覆范围、基坑模型、基坑中心提示和监测点。只列出当前已加载、可访问的逻辑对象，不列内部编辑手柄或不可访问对象。

每项可显隐，适用对象可定位或进入原配置；每类支持全显、全隐。人员模型、责任区和工作区独立控制，机械模型与倾覆范围也独立控制。标签总开关控制安全管控、标绘附属名称和基坑名牌；文字标绘正文保留，演示副本的识别提示保留。

## 合并显示分组

1. 在“按类型”目录勾选对象左侧的选择框，可以跨类型选择，例如一台吊机、它的倾覆范围、一个工作区和一段限界。
2. 点击“选中项建组”，填写名称并保存。
3. 在“我的分组”中使用复选框或全显、全隐按钮，一起控制成员。还可重命名、调整成员或解散分组。

同一对象可以加入多个组。组的全选、部分选中或未选中状态由成员当前显示情况决定；操作一个组会同步影响其他组对相同成员的显示状态。解散组只移除组，不删除模型、区域或业务记录，也不改变成员当前显隐。

分组和显示偏好保存在当前浏览器，按账号和项目隔离；不作为多人共享的项目业务配置。临时未加载的成员会标明不可用，恢复加载后继续按原偏好显示。修改成员时以当前勾选清单为准。存储不可用时会在面板提示，当前会话仍可操作。

## 统计与数据边界

统一显示开关仅改变渲染，不保存机械位置、尺寸、业务可见字段或标绘修改时间，不改变安全限界选用关系。隐藏机械、限界、工作区或人物，不会停止既有筛查或定位判定，也不会清除风险和越界统计。显示偏好不能突破现有项目权限。

上一版的定位器接入边界不变：目前提供接口和本地模拟，尚未连接现场定位器或外部声光、短信设备。机械演示仍是几何运动演示。

验收记录见同目录 `validation.md` / `validation.json`，复现工具为 `tools/verify-scene-display.mjs`。验收使用隔离的临时资料和数据库；现场模型效果仍需在本地部署后核对。原有少量贴附填充边线拖影的显示限制未在此轮扩展修复。
