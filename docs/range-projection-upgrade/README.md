# 范围配色与按角度倾覆投影

适用仓库：`cristinomcleary-ship-it/cesium`，分支：`codex/machinery-integration-20261013`。在透明限界墙、右侧分类分组显示的基础上继续升级。

范围动态效果、默认 0–90° 扫掠外包及 HTTP 定位器接入见 [范围效果与定位接入](../range-effects-upgrade/README.md)。

## 选择范围颜色

进入“邻近营业线管控 → 参数编辑 → 显示效果”。

| 显示分类 | 可调整颜色 |
| --- | --- |
| 安全限界 | 限界平面、立面墙及轮廓共用一种颜色 |
| 人员区域 | 防护责任区、人员工作区分别设置 |
| 倾覆影响区 | 倾覆范围、侵限相交区、计算支承区分别设置 |

点击色块选择颜色，填充、轮廓和图例立即更新。颜色按当前浏览器、账号和项目保存，“恢复默认”会恢复本模块全部显示偏好。颜色不修改区域坐标、机械参数、关联限界或定位判定。

人员工作区保持用户选定的底色；定位点及状态文字仍表达区内、越界和待核实。

## 按方向和倾角查看机械范围

1. 在“机械”页选择已布置、支承配置有效的机械。
2. 点击“按角度查看范围”。系统创建当前机械的演示副本，保留原机械作参照。
3. 调整“倾覆方向”：0° 北、90° 东、180° 南、270° 西；任意方向连续计算，不吸附到少数支承边。
4. 调整“倾倒角度”：0–90°，或使用播放、暂停、复位。
5. 在“显示效果 → 倾覆影响区”选择展示模式。

| 模式 | 展示内容 |
| --- | --- |
| 当前方向 / 倾角投影 | 查看中的机械显示当前姿态的模型投影，隐藏它原来的全方向外包及相交高亮 |
| 全方向保守外包 | 保留原有全方向筛查外包，仍可观看三维运动 |
| 投影 + 保守外包 | 同时显示当前投影和全方向轮廓，方便对照 |

模式只影响正在查看的机械。其余机械仍按全方向外包显示；退出演示后恢复该机械的外包。右侧分类及分组中的“倾覆影响区”开关同时控制其投影与外包。

投影取自机械当前完整三角网格，包含已设置的尺寸、臂架姿态、支腿和朝向。模型绕该方向的地面支承线旋转，所有三角面投影到工点水平面后取并集，因此可表达凹部、可分辨孔隙和分离部件；不会将整个形状再填成圆或凸包。

投影采用显示栅格，默认格长不小于 0.1 米、最长边上限 384 格，面板显示当前格长和近似面积。边界存在格网误差，较小孔隙可能合并；这不是测量级矢量轮廓。投影与三维副本按同一方向、倾角更新，计算期间保留上一对画面并显示状态。

## 筛查口径与几何边界

潜在侵限数量及结果列表仍按全方向保守外包计算，不会因调整当前演示方向、倾角、颜色或显隐而改变。当前角度投影描述这一姿态下的水平占地，不是 0° 到该角度的整个扫掠区域，也不是全部可能倒伏方向的范围。

几何计算假设固定支承线与水平地面。方位不是支承边法向时，支承线可能只经过支承凸包的一个角点。系统计算模型首次触地角；超过后标记“几何续转”，不将穿地姿态表示为真实接地状态。模型运动未计算荷载、滑移、碰撞后的停止、解体和地基变化。

“依附模型 / 地形”仅调整投影的可视呈现，不会使倾覆计算自动适应现场坡面。现场支承、尺寸及模型附件仍须核对。演示不保存新的机械站位；方位和倾角随演示会话使用，退出后清除。

验证记录见本目录 `validation.md`。部署时保留原有数据库、模型文件、账号及定位器设置。
