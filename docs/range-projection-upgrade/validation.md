23° 方位下，0° / 30° / 60° / 90° 的 mask 占用格数分别为 **424 / 535 / 594 / 572**，显示面积分别为 **4.24 / 5.35 / 5.94 / 5.72 m²**；格长均为 **0.10 m**。面积是占用格面积，不是测量级矢量面积。该格长的单格对角线约 **0.142 m**，边界有量化误差，小于格长的孔隙可能合并。

根代理已目视通过本地 30° 和 90° 两张实际画布截图，模型姿态与非圆形投影相符。截图未提交。此验证使用合成地形及软件 WebGL，不代替真实测绘现场或各硬件 GPU 的认证；既有微量贴附细线残影未在本轮扩大排查。几何投影与超过首次触地后的继续旋转不表示物理倾覆预测。
