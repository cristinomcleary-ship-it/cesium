# 临建规划

在工程数据浏览器顶部打开 **临建规划**。也可从现场工作台的 **现场对象 → 新增与工程配置 → 临建规划** 进入。已保存方案列入右侧场景显示目录，可单独定位、显隐或加入个人分组。

## 图纸与坐标

在 **倾斜摄影** 中加载目标实景 3D Tiles 后，进入 **临建规划** 选择该模型和设施类型。导入 DWG、文本 DXF 或平台 CADIMPORT，可按图层选取具体图元。误选文件时点击 **移除图纸** 或 **更换图纸**。移除会取消当前图纸的读取、计算及相关预览，已经保存的方案仍可从列表复核。

工程独立坐标需要图纸控制点、对应的 WGS84 经纬度、图纸单位、XY 顺序和旋转角。CGCS2000 高斯坐标需要中央子午线，东坐标中含带号时还需指定带号。经纬度模式直接读取地理坐标。

### 在摄影模型上核对位置

选择图元后，工程独立坐标可用两个图纸与摄影模型均能辨认的控制点定位。先为 A 填写 CAD 坐标和 WGS84 经纬度，再展开第二控制点，为 B 填写相应坐标。也可以用 **从图纸选 A/B 点** 在二维图中选取原图顶点，用 **从摄影模型拾取 A/B 点** 在目标模型上选取同一位置。首次选择图元时，空白的 CAD 控制点框会显示该图元首、末顶点，使用时应与实际选取的同名点核对。

点击 **应用两点校准**，平台以 A 为固定点、用 A 到 B 的方向计算旋转角，同时显示图纸基线、模型基线和 B 点平面偏差（米）。图纸的单位和设计路宽继续由输入参数控制。如果两条基线长度差异明显，可复核图元、单位、XY 顺序和所选地物。对于以米或毫米表示的国家 2000 平面坐标，默认选择 **国家 2000（CGCS2000）· 高斯平面坐标**。按测量资料直接填写中央子午线（支持十进制度或度分秒），或选择 3°/6° 分带并输入带号。按图纸坐标顺序设置东、北，东坐标确实带有带号前缀时再勾选“东坐标含带号”。界面会显示中央子午线以及图上起点换算后的经纬度，可与已知测量点核对。

如果图纸采用国家 2000、摄影模型的实景位置仍有偏差，展开 **用同名点核对摄影模型的平面偏差**。在图纸与模型上选取同一清晰地物，点击 **查看东、北偏差**。核对投影参数与点位后，可选择 **对当前方案应用平移** 并重做叠图预览。系统记录本次东、北改正数，可随时恢复原始投影位置；应用改正时中心线、桩号、路宽和设计面积保持原值。

点击 **在摄影模型上预览图纸**，即可在建模前查看位置。施工便道预览保留所选 CAD 中心线的全长、弯道和图纸首末点。“定位到图纸”对准整条中心线。青色实线表示该段取得所选摄影模型的表面高程，橙色虚线表示模型外或模型内部缺测的线位；端点缺测时仍显示其图纸位置。橙色段的绘制高度仅供查看平面位置。已填路宽时，黄色横尺显示有模型采样支持的路宽位置。驻地与钢筋场显示场界和所选建筑轮廓。图纸预览沿线在所选模型上抽样以区分线型。**计算并预览**按另行设置的网格采样间距生成三维实体和方量，只取有模型高程支持的区域。可隐藏或再次定位到叠图。更换图纸、模型或坐标参数后可重新预览。

## 施工便道

1. 上传包含**道路中心线**的平面图，选择一条开放、连续的线形。核对平面总长、起点和终点的 CAD 坐标。单个图元按原绘制方向起算。同图层中首尾相接、没有分支的直线和圆弧可选成一条组合中心线，组合后的方向与组内第一个 CAD 图元的绘制方向一致。起终点坐标以界面标注为准，可用 **交换起终点** 改从另一端起算。模型外的一段也保留在设计里程中。
2. 输入**路面宽度、硬化厚度、地基处理深度和路基边坡高宽比**。路面横向取平，两个深度均为竖向距离。边坡由两侧路肩向下、向外展开。以高宽比 1∶1.5 为例，每下降 1 m，每侧外放 1.5 m。界面断面图列出路面、硬化层底和地基处理底宽度。
3. 按**水平里程**输入纵坡的起止位置及百分比，所有坡段从 0 连续接至路线总长。沿当前起点到终点上升填正值，下降填负值。相邻坡段在变坡点衔接，标高逐段累计。
4. 填写**校准桩号处路面顶相对标高**。起点 K0+000.000 有模型高程时，就在起点校准。起点缺测时，平台在半幅路宽以内逐圈取样，最大搜索半径为 10 m，用最近一圈命中的模型点作为 K0 的高程零点。邻域也缺测时，沿原设计方向找到首个形成有效路面网格的桩号，在该桩号施加输入的相对标高。高于所取表面填正值，低于填负值。交换起终点后，按新方向重新确定校准点并填写相对标高。
5. 点击 **计算并预览**。在结果中核对高程校准方式、对应桩号、有效路面首末桩号、有效面积、舍弃面积和挖填方，再保存方案。

例如，K0 和附近都在模型外，首个可计量路面桩号为 K0+080.000，输入 +0.30 m，则 K0+080.000 的设计路面顶高于取高点模型表面 0.30 m。若其后 20 m 的纵坡为 +2%，K0+100.000 的设计路面顶相对同一零点为 +0.70 m。中间缺测段跳过建模和计量，后续覆盖段仍采用原桩号和同一纵坡线。

**分段示例。** 中心线 A(0,0) → B(40,0) → C(40,30)，单位为米，平面总长 70 m。以 A 处的摄影表面为 ±0.000 m，输入 A 便道顶标高 +0.350 m。A 到 B 的纵坡为 +2%，B 顶标高为 +1.150 m。B 到 C 的纵坡为 −1%，C 顶标高为 +0.850 m。三个数值均相对于 A 处的摄影表面。

**断面示例。** 路宽 4 m，硬化厚 0.5 m，地基处理深 0.5 m，边坡高宽比 1∶1。硬化底宽 5 m，处理底宽 6 m。若是一段 20 m 的直线便道，原地面水平、与路面顶齐平且完全覆盖，处理底面深 1 m，对应预计挖方 120 m³。该数值按处理底宽计算，结构各层材料体积可根据各自的梯形断面另行计算。

### 转弯与折返

直角、连续转弯和圆弧仍使用同一条 CAD 中心线及原来的路宽、结构深度与边坡参数。中心线在直线段上的附加分点保留原里程含义。平台生成路基时会处理转角内侧的折叠，使重合的平面范围只参与一次面积和土方计算。模型覆盖边缘仍按采样结果舍弃，纵坡继续按原设计里程累计。

整条路线可以一次计算。平台沿路线组织网格，仅在会影响同一片路基的弯道附近计算轮廓交叠，并按所填间距分批读取摄影模型高程。界面显示当前分区和累计取样位置数，计算过程中可取消。所有分区共用原设计桩号、纵坡和本次确定的相对高程基准，保存后仍是一个方案。在“查看计算依据”中可核对采样间距、采样点数和读取批次。

当两段路基长期紧贴、占地重合时，平台会一起处理这片区域，避免在分区边界重复计量。若一个无法安全分开的重合区单独就需要超过 50 万个网格点，界面会指出该区段的起止里程，便于核对图纸单位、路基宽度和间距。

若中心线真实穿过自身、沿原路重走，或相隔较远的两个里程占用同一区域且设计高程冲突，错误信息会列出两个冲突里程，并在 CAD 预览中标出对应线段和坐标。此时可按位置检查是否选入了回头的重复图元，或该处是否确实属于两条相交道路。已经保存的方案保留原计算结果；重新计算时采用当前的弯道处理方式。

## 项目驻地与钢筋加工场

1. 在 **临建规划** 选择设施类型和已加载的倾斜摄影模型。导入场地 CAD，选择该设施的闭合外边界。切换临建类型后，请在图中重新选择对应的场界和基准点。若同一图纸包含钢筋场和驻地，请分别选择各自的边界，建立两个方案。
2. 选择 **自动布置标准模型**。只有外边界也可生成设施。设置图纸坐标、基准点、硬化面相对标高、处理深度和东西、南北坡度，勾选 **已核对设计标高、断面参数与坡度**。可先用 **在摄影模型上预览图纸** 对照现场位置。
3. 点击 **在摄影场景中生成模型**。平台根据 CAD 场界的方向、所选摄影模型的有效覆盖和设计场坪高程布置设施。标准布局的展示尺寸为 48 × 30 m，模型各方向按同一比例缩放到 65% 至 100%，需在场界内有至少 31.2 × 19.5 m 的连续有效区域，可随场界转向。标准尺寸用于三维布置，具体建筑设计尺寸应按施工图核对。钢筋加工场包含封闭厂房及加工区设施，项目驻地包含办公楼、宿舍楼和门卫室。勾选 **驻地院内布置国旗台和停车区** 可一并显示相应设施。查看主场景并点击 **保存方案**。
4. 若有建筑详图，选择 **按 CAD 建筑轮廓布置**，选取房屋或厂房的闭合轮廓并填写统一建筑高度。只需硬化地面和方量时，选择 **仅生成硬化场坪**。建筑和场内设施作为三维展示，土方以有效场坪网格计量。

### 已保存的场坪

打开 **已保存方案**。对于原来只生成硬化面的钢筋场或驻地，先对照原方案行的图名、图层和图元编号，再点击 **补建标准模型** 和 **定位**。系统沿用该方案的场界和设计场坪，保存到同一条方案记录。原方案处于隐藏状态时，点击 **显示** 即可查看。若有效覆盖不足以容纳整套标准设施，按界面提示核对 CAD 边界、摄影覆盖和采样间距，也可采用自选建筑轮廓。

**查看钢筋加工场参考样式**、**查看项目驻地参考样式** 可打开独立预览，用于旋转、缩放和查看外观细节。

路面纹理沿道路桩号排布；场坪、屋面和边坡使用不同的表面材质。常规视图按实际遮挡关系显示，检查原地面以下的设计面时可勾选 **透视显示埋入原地面的设计面**。

在计算结果处可隐藏、显示或移除未保存的模型预览，保留图纸和设计参数。保存后，在临建规划的方案列表或右侧 **场景显示 → 临建规划** 中可管理显隐或删除。删除确认后，平台同时移除该方案的三维模型、已存方量和当前个人分组中的成员。需要暂时清理视野时可使用隐藏。

## 高程与数量口径

所有高差和厚度以米计。下式中的“模型高程”使用同一摄影模型的高程基准。它与现场采用的水准基准之间如有偏差，需通过实测控制点核对。

| 计算项 | 高程或数量 |
| --- | --- |
| 基准点硬化面 | 基准点的模型表面高程 + 输入的硬化面相对标高 |
| 其他位置硬化面 | 便道沿中心线逐段累加纵坡高差；场地按东西、南北方向设计坡度推算 |
| 地基处理顶面 | 硬化面 − 硬化面到地基处理顶面的竖向厚度 |
| 计算底面 | 地基处理顶面 − 地基处理深度（场地填写处理顶面以下另挖深度） |
| 挖方、填方 | 在有效区域内，分别积分“现状模型表面高于计算底面”和“现状模型表面低于计算底面”的高差 |

例如，现状平地为 ±0.000，设计硬化面为 +0.200 m，至地基处理顶面厚 0.500 m。计算至处理顶面的挖深为 0.300 m。若另挖处理层 0.200 m，挖深为 0.500 m。在有效面积 100 m² 的水平场地上，两种计量口径分别为 30 m³ 和 50 m³。

## 核对边界与精度

- 只对选定倾斜摄影取样。模型外和模型空洞处不补地形高程。便道邻近取高仅用于建立纵向设计基准，模型外和空洞处的缺测网格均从三维实体和工程量中剔除。全线未形成有效网格时，可核对中心线、模型和采样间距。驻地或钢筋场的基准点无有效表面时，可重新选点。挖填交界处分别积分，单列挖方和填方。
- 有效边界按给定间距的采样网格近似。核对小尺度空洞、狭长便道或陡坎时，可缩小间距对比两次结果。便道全线自动分批，采样越密，需要读取的模型表面位置越多。项目驻地、钢筋加工场的场地网格沿用单场地采样上限。
- 摄影表面可能包含植被、堆料和既有建筑。土方是所选边界内的几何估算。现场计量应核对原地面测量成果，以及设计要求的边坡、工作面、局部换填范围和开挖深度。

临建规划沿用平台已关联工程场景的项目和账号权限。保存的位置是该项目在当前浏览器中的本地方案库。在结果的“查看计算依据”中可核对图名、图层、图元、基准点和断面附件。

文本 DXF 支持常用直线、圆弧和多段线。带原始平面圆弧参数且以长度为单位的 CAD 按弧长计算里程；仅保留离散点的旧文件按现有折线长度计算。DWG、CADIMPORT 或 DXF 中仅有样条曲线控制点时，请在制图软件内按项目精度转换为普通多段线后再导入。便道按设计处理底面的有效投影范围计算。施工另需的临时开挖放坡、工作面和排水沟应按现场方案单独复核。
