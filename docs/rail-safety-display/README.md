# 防护责任区、倾覆影响区与人员显示

在原有工作台打开 **邻近营业线管控**，进入面板的 **显示效果**。这组设置立即生效，无需点击业务配置的“保存配置”。

## 区域显示

“防护责任区”和“倾覆影响区”分别设置，互不联动。

| 选项 | 适用场景 |
| --- | --- |
| 依附模型 + 地形 | 把范围颜色和边线投到已加载的倾斜摄影 / 3D Tiles 及地形表面，适合地面有起伏或构筑物遮挡的场景。默认采用此方式。 |
| 仅贴地形 | 只投到地形表面，适合不希望构筑物表面着色时使用。上方模型仍可能遮挡下方地形。 |
| 原始高程 | 沿已保存顶点的高程显示，适合检查原始绘制位置。可能被更高的模型表面遮挡。 |
| 填充 / 仅边线 | 选择着色范围或只保留边界。 |
| 填充浓度、边线宽度 | 根据影像背景调整范围的醒目程度；浓度越高，填充越明显。 |

建议先使用“依附模型 + 地形”和“填充 + 边线”，再按背景调整填充浓度和边线宽度。依附模型是从上方向表面投色，同一平面范围内的桥面、屋顶等表面也可能着色；它不表示人员可以在这些表面通行。

红色潜在侵限相交区会保持强调显示，不会因普通范围切换为“仅边线”而失去填充。

## 防护人员

默认使用戴黄色安全帽、穿橙色反光背心的人物模型，并保留姓名。可切换回点标记，也可调整人物显示大小和朝向。模型为项目自带资源，无需联网下载。

人物脚底使用已保存的人员站位高程，不会自动移到头顶的桥面。若站位本身不准确，请在人员编辑项中重新点选站位并保存。

人物显示大小及远景可见性处理仅用于识别人员，不代表真实身高，也不参与机械或责任区的几何计算。

## 设置保存

显示设置按当前浏览器、项目和用户分别记住，刷新页面后恢复。“恢复默认”只重置显示效果，不删除人员、区域或机械配置。更换浏览器、清除浏览器数据后需重新设置。

区域贴合、填充、透明度、人物显示均不修改原始坐标、不重算倾覆外包，也不改变已有关联和侵限判断。原有图层开关继续有效。

依附显示时，超过 32 个顶点的密集凸边界采用最大 5 cm 平面偏差、至少保留 99% 面积的显示简化，以减少绘制拖影。小区域、狭窄区域、凹多边形或不满足保留条件的区域保留全部顶点；原始高程模式与几何筛查始终使用完整边界。

## 验证

`npm run build` 已通过。显示设置、倾覆几何与场景回归测试共 24 项通过：

```sh
node --import ./tools/test-module-loader.mjs --experimental-transform-types --test src/railSafetyDisplay.test.ts src/railSafetyGeometry.test.ts src/railSafetyScene.test.ts
```

浏览器验收脚本为 `tools/verify-rail-safety-display.mjs`，使用独立测试数据和合成起伏 3D Tiles，不读取或修改现场项目数据。

在本次 Chromium / SwiftShader 合成场景中，组合绘制填充与贴附边线时仍观察到少量细线残影；关闭其中一类后消失，未确定为单一实体或驱动问题。该限制和最终功能验收结果记录在同目录验收报告中。尚未使用现场倾斜摄影数据验证此项。
