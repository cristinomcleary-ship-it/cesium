上一轮已记录的部分贴附视角微量橙色拖影仍作为已知显示限制，本轮没有扩大排查，也不宣称完全无伪影。最终两张截图分别展示模拟越界和机械演示；截图保留在本地 `output/rail-safety-extensions/`，不提交二进制证据。

复现：

```sh
PLAYWRIGHT_MODULE=/path/to/playwright-core/index.mjs \
BROWSER_LAUNCH_OPTIONS=/path/to/launch_options.mjs \
node tools/verify-rail-safety-extensions.mjs
```

`BROWSER_LAUNCH_OPTIONS` 默认导出 Chromium launch options；也可使用本机 Playwright 或 `BROWSER_EXECUTABLE`。通过 `RAIL_SAFETY_EXTENSIONS_VERIFY_PORT` 改专用端口（端口被占用会直接失败，不会转占其他端口），`RAIL_SAFETY_EXTENSIONS_VERIFY_OUT` 改输出目录。每次运行创建新的 `tmp/rail-safety-extensions-*` 数据目录并在结束时关闭自己的服务和浏览器。
