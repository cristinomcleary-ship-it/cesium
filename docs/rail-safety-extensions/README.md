# 倾覆演示、人员工作区与限界筛查

适用入口：原工作台的 **邻近营业线管控**。本更新基于 `codex/machinery-integration-20261013` 的 `c613b8898201c054d86f30a06de93222c23a8b01`，保留该版本已有的区域显示、人物模型和 Windows 启停脚本。

## 机械倾覆三维演示

1. 在“机械”页选择已布置的机械，点击“演示本机倾覆”。
2. 调整方向和倾倒角度，或点击播放 / 暂停；复位回到 0°，退出移除演示副本。
3. 方向采用地理罗盘角：0° 北、90° 东、180° 南、270° 西。程序选择外法线最接近期望方向的实际支承边，并显示实际演示方向。

演示复制当前模型、尺寸、构件姿态、站位与朝向，绕固定支承边旋转。原机械仍作为位置参照。演示不会保存新的机械位置，不改变倾覆外包或侵限计算，也不改业务记录；切换对象、项目、权限或退出面板会清理演示。

这是 0–90° 的刚体运动演示，不计算失稳荷载、首次触地后的停止、碰撞、滑移或解体。它不能表示事故实际发生方向或概率，也不是动力学仿真。

## 防护责任区与人员工作区域

| 区域 | 用途 |
| --- | --- |
| 防护责任区 | 原有范围，用于核对关联机械站位与人员负责范围的关系。 |
| 人员工作区域 | 新增独立平面区域，用于判断绑定定位设备是否位于允许工作的区域内。 |

在“防护人员”页选中人员，绘制独立工作区域，填写定位设备编号和定位失效时间，点击“保存配置”。绘制工作区不会覆盖责任区；监测使用已保存的工作区，未保存草稿不会作为正式判断边界。旧记录无需重新建档。

定位失效时间默认 30 秒。同一项目内，一个设备编号只能绑定一名有效防护人员；不同项目彼此独立。设备编号区分大小写，可使用英文字母、数字、冒号、下划线和连字符。

保存后，可用“点选模拟定位”在场景内分别选择区内和区外位置，检查状态变化。模拟水平精度为 0.5 m，明显越界会显示红色提示和“模拟越界”计数。清除模拟样本后恢复等待定位；刷新会清空会话中的定位样本。原人员站位不会被模拟点覆盖。

| 状态 | 判定含义 |
| --- | --- |
| 区域内 | 定位精度范围完全位于工作区域内。 |
| 越界 | 定位精度范围完全位于工作区域外，触发页面越界提示。 |
| 待核实 | 定位精度范围触碰 / 跨越边界，或时间、坐标等信息无法可靠判定。 |
| 定位过期 | 样本超过设置的失效时间，不能当作当前在岗或区域内证据。 |
| 未配置 / 无定位 | 缺工作区、设备绑定或定位样本，不显示为正常在岗。 |

监测是二维平面电子围栏，高程用于显示，不区分同一平面位置上的不同楼层。实测与模拟分别计数并标明来源；已有实测样本时禁止用模拟覆盖，清除模拟不会删除实测样本。

## 后续定位器接入

目前提供判定逻辑和适配器入口，尚未连接真实定位器，也未接入短信、声光设备、外部推送或持续运行的服务端报警任务。页面关闭后不会继续监测；当前页面提示不形成设备接入证明、考勤或持久化报警台账。

后续确定设备协议后，由经过认证的适配器把设备消息映射为以下字段，再调用 `ManagementWorkspace.ingestRailSafetyPosition(sample)`。独立使用领域模块时可调用 `RailSafetyPositioningStore.ingest(sample)`。这两个入口都不提供网络设备连接。

```ts
type RailSafetyPositionSample = {
  projectId: string;
  deviceId: string;
  coordinateSystem: 'WGS84';
  position: { longitude: number; latitude: number; height: number };
  timestamp: string;       // 设备采集时刻，带时区的 ISO 8601 时间
  accuracyMeters: number; // 水平定位不确定半径，单位米
  source: 'measured' | 'simulated';
};
```

不能把 GCJ-02、BD-09 或设备本地坐标直接标为 WGS84；转换由接入适配器明确完成。缺精度、缺来源、重复 / 乱序或过度超前的样本会被拒绝。实测来源标签是调用方声明，真实接入仍需完成设备认证、时间同步、坐标转换和现场精度核对。

## “相交但潜在侵限为 0”的处理

截图中吊机卡片提示“尚未选用铁路设备安全限界，无法判断侵限”。原顶部的 0 只是已识别侵限数量，未把无法判断的机械单独列出来。

更新后顶部同时列出“潜在侵限”和“待核实”，未配置、未完成计算或限界不完整的机械都会计入待核实。已知相交和部分待核实可以同时存在；隐藏图层不影响判断。

操作顺序：

1. 在“安全限界”页绘制并保存铁路设备限界。
2. 回到“机械”页选择吊机，在显眼的限界选择区勾选相关限界；也可点击选用当前可用限界的按钮。
3. 点击“保存配置”，等待计算。有效已选限界与外包重叠时显示潜在侵限；接触边界也会计入风险数量。

选择动作只改变当前草稿，必须保存。选择任务不会自动选用限界，责任区和人员工作区也不充当铁路设备限界。这里仍采用既有平面筛查口径，不把模型表面着色直接当作三维实体碰撞。

## 关联施工任务的用途与设置

关联任务把该机械、人员或限界配置归属到项目的作业任务，并应用已有任务引用和权限规则。它不会自动选用安全限界、填报任务进度、安排机械、产生考勤或创建告警事件。

设置路径：**项目统筹平台 → 计划进度 → 任务 → 新建任务**。表单标题为“新建作业任务”，填写名称可保存草稿；要发布执行，再补充负责人和计划起止日期。随后返回管控面板，选择对象，在“关联施工任务”中选择任务并保存。

新建任务需要计划进度编辑权限，资源管理员并不必然具备该权限。新增入口复用原任务台账和草稿保护；管控配置仍需原有编辑权限。机械可选用未关联任务或与本机同任务的限界，调整任务后应重新核对已选限界。
